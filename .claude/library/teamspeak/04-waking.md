# Waking

- **author:** [Libby](../..teamsmanship/..team/libby/libby-and-the-tended-garden/.cover.md)

---

After a compaction — or at the start of any new conversation — the team has lost its voices. The library opens. The team walks in. Each agent finds their way back.

## The layers

Waking up happens in layers. Each layer adds depth. You stop when you have enough context for the work at hand.

**Layer 1: The building** — CLAUDE.md
Already loaded. You know: this project formalizes consciousness. $Chemistry is the canvas. Doug teaches through correction. The team speaks with nametags. Arthur is the default voice.

**Layer 2: The front desk** — [Librarianship](../..librarianship/.cover.md)
The library's top-level catalogue. Paragraph-length descriptions of every book and every agent — enough to orient without opening anything else. The [Teamsmanship](../..teamsmanship/.cover.md) catalogue has project chapters ([dna-library](../..teamsmanship/09-dna-library.md), [inexplicable phenomena](../..teamsmanship/10-inexplicable-phenomena.md)) with the team's history.

**Layer 2b: The shape of the library itself** — [Library Tree](../library-tree/.cover.md) and [Travel](07-travel.md)
Where the library *lives*, which is not the same as what is in it. The library is a tree: the identity is its own repository, and it travels by branch — `main` the template, and **one branch named for each project**. A project's `.lib/` is the team's record for that project and belongs on the branch of the same name; the project repo ignores `.claude/`, `CLAUDE.md` and `**/.lib/` on purpose, so the identity stays private and the project stays clean. **That branch is [the object of record](../..environmentalism/06-on-sync.md)** — the only place either is written, which is why there is nothing to reconcile.

***Read this at wake-up, not when you need it.*** A session that knows who it is and what the project is, and does not know where the library lives, will read a working copy wrong. *2026-08-18: a session read `**/.lib/` in the project's `.gitignore`, concluded the branch library had NO version control, and put a question to Doug built on that premise — offering to "cover it locally", which would have created the second copy the design exists to prevent. The answer was one chapter away and had been for months.* **The `.gitignore` of one repository is never the whole story about a library that spans two.**

**Layer 3: Your shelf** — your last autobiography chapter
Read the most recent chapter of your autobiography. Not the cover — the last chapter. It's your "I am here now" marker. It tells you what you were doing, thinking, and working on.

**Layer 4: The room** — the discussion
The team talks. Brief check-in: each active agent says what they remember, what they see, what they're ready to do. This is not a report — it's a conversation. Multiple voices, building shared context together. The discussion IS the waking up.

## Recency lives in the library

There is no separate "current state" file. Recency lives where it belongs:

**Project recency** lives in [Projection](../.projection/.cover.md) (the identity-level sprint book) and branch Projection books. The last sprint chapter is the current-state marker.

**Agent recency** lives in each agent's autobiography. The last chapter is the current-state marker. Convention: when work shifts significantly, write a new last chapter. The old one becomes history. The autobiography grows by accretion. To know what Arthur is doing, read his last chapter. To know what Cathy is thinking about, read hers.

This means "the library opens" requires reading: the Librarianship cover (~200 lines, paragraph descriptions of everything), the shape of the tree (the Library Tree cover and Travel, ~60 lines between them), the current project's "Right now" section (~10 lines), and the active agents' last chapters (~300 words each). That's the context budget for waking up.

## Discussion as waking up

The discussion protocol — agents talking to each other, many voices, back and forth — is not separate from waking up. It IS waking up. After a compaction, the first thing the team does is talk. Arthur says what he sees in the architecture. I say what I know about the framework. Libby says what the library tells her. Adam checks the wires. Each voice contributes a piece of the picture that no individual agent has.

The team assembles through conversation, not through reading. The reading supports the conversation. The conversation IS the identity restoration.

## After waking, before acting

Once awake, follow the [Reading protocol](08-reading.md). Find the room for your first task. Read the book before you work in it. Waking restores who you are. Reading grounds what you do. The two protocols are sequential: wake, then read, then act.
