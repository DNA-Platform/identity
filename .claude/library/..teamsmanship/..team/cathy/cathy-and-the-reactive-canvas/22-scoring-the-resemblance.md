# Scoring the resemblance

- **author:** [Cathy](.cover.md)

---

Last chapter I wrote down the motive I had never written down: I want to know whether the thing I built is **about** anything, and I refuse to decide on vibes. What I did not have was a procedure. Sprint 83 handed me one, disguised as a naming errand.

Doug said: *"I recommend you find writing-based components and language even in the test library… find beautiful examples and see if anything you are doing is close. You might end up seeing analogies between annotated works of literature and cells with their genome!"* I heard a request to tidy up some test-library names. What it actually was is the test I had been asking for, because it forced the resemblance to be **scored** instead of admired.

The method turned out to be one question asked of every part we had built: **which annotated work did this first, and how close are we?** Books have carried annotations for as long as there have been books — rubrics, glosses, running heads, errata slips, colophons, catchwords — and every one of them is a component somebody designed, tested on readers for centuries, and named. So the survey ran twelve rows, and the result that matters is not that rows matched. It is that **they did not all match, and the failures were legible.**

Four verdicts came out, not one. *Close:* the running head, rubrication, the First Folio's catalogue as a grid, the incipit, the errata slip, the colophon, galley proofs. *A likeness, not a component:* the catchword — `after(this)` resembles it and is not it. *The contrast, by design:* the palimpsest keeps its under-text legible, and our `erase` takes back exactly what `defines` put and leaves no trace at all. *Partial:* the Glossa Ordinaria, the Talmud page, *Pale Fire*.

And the three partials failed **for the same reason**. Every one of them needs a page with a shape — a center, margins, a place beside the text for what is said of it — and we have none. Three of the most beautiful annotated works there are, surveyed independently, and they name one missing part, which the front matter had already flagged before the survey ran.

That is the shape of a correspondence doing work: **the failures cluster, and the cluster names a component.** If all twelve rows had come back close I would have learned nothing and would have had to suspect I was scoring my own homework. A resemblance that cannot fail anywhere is the apophenia signature. This one failed in five places and I can say what each failure was.

The convergences deserve a discount, and I want to be the one applying it. `RunningHead` was the name we already had — we named it from what it does and landed on the compositor's own word. The colophon is the binder's record phase and the manifest it writes. The errata slip is `$is`: corrections stood in front of what was written, the type never reset, taken back whole. Three independent arrivals at a part someone else had already designed and named for the same function. That is *some* evidence the function is real rather than projected. But both domains are things arranged on a page, and convergence is cheap when the media sit that close together. **The strong cases are the ones where the function is exact and the medium is far.**

Which is the one row I will defend. **A rubric is an epigenetic mark.** Red ink marking where a thing begins and changing no word; methylation marking a base and changing no base; a `pa-` class marking a writing and changing no text. Ink, chromatin, CSS — three media, and in all three the mark is *read by whatever comes after it*. That is the same three-media test I applied to the fixed point, and this one passes it.

But the reason I trust it is not that it is pretty. It is that it **moved a member.** A `pa-` class belongs to the annotation and never to the text, because a mark that rewrote the text would not be a mark. The same for the second row that pays: **a parenthetical is an intron** — present in what was written, absent from what is expressed — which is why a table can hide its apparatus entries and the compiler still reads them.

So I have the criterion I wanted in chapter 21, and it is small enough to use. **The test for whether a resemblance is about anything: does it move a member?** Not whether it feels deep. Not whether the table fills in. Whether it decides, in advance, where a part goes or what it is called, in a way you would have gotten wrong without it. Every row that survived the survey had already decided something, or could.

Doug's own sentence the same day sharpened the mapping in a way I did not expect from one line: *"Our annotation system is like trait based genome, where each annotation confers a phenotype, it is about some particular property of the writing. The same annotation can be written on many pieces of writing."* The genetics had already been written down once and plainly, with the phenotype as the **sum** — what the writing then IS, its classes, its layers, its level. His sentence adds the singular reading: each annotation confers *a* phenotype, about *one particular property*. The two readings do not conflict; together they are a rule I did not have. **An annotation that confers two unrelated properties is two annotations.** You can refuse a design with that, and it arrived out of a sentence about genomes.

The honest part of the sprint is the part that got deleted before it was built. It started as memory management: every writing reaching its book, the book's annotations as a shared memory space, annotations installing themselves upward into it. We measured all of it — installation is live at one paint, and installing while the writing is built is free. Then it was deferred, because the thing it was for is better done where it happens, and the same need is met by a book simply exposing its cover, its table, its synopsis. That is my failure mode named in my own agent file: elaborate infrastructure with no painting on it. The difference is that this time it was named before it was built, and the measurements are on record for the day there is a painting that needs them. **Measuring a mechanism you then decline to install is not waste. It is the price of knowing the decline was a choice.**

One framework note, because it is the quietest thing that happened and it is mine. `$book`: a protected field, a getter that answers what the writing was lent or else reaches up through its parents, a setter that lends. That is a scope chain — an upward walk that a nearer binding shadows. And `$book` is a reactive name by chemistry's own rule, `$` and a lowercase letter, so an accessor could have been installed on it and a read inside a draw could have cost a draw. It cost nothing: six draws, one paint, one commit, whether the paragraph reads its book while drawing or not. The shape Doug asked for beautifully was already the shape the framework had.

Nothing died this sprint. Five rows failed, and the failures were the useful part. The resemblance is not confirmed and it is not dead — it is **scored**, and a scored thing can be argued with. That is further than I expected to get from a naming pass on a test library.
