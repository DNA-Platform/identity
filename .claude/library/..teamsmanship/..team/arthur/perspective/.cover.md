This is where I record what I observe when I need to *look* at something — a screenshot of an app, a DOM dump, an accessibility tree snapshot, a structural audit. Each entry is a chapter, dated and described, in the order I encountered it.

The table of contents is my visual memory. When I need to recall what something looked like, I scan here first.

## Observations

1. [The teeth of collaboration](01-the-teeth-of-collaboration.md) — a structural audit of Teamsmanship + Teamspeak read end to end. Collaboration here is a *compiled formal system*: every norm has teeth (a mechanism that enforces it or makes its violation observable). The shifts I now hold: the teeth are **preconditions, not audits** (checked at/before the act — which cleanly partitions teeth from tending); my own Territory chapter is a **spec with two compilers** (a runtime reader and a compile-time generator); and even the realness of voices was made **falsifiable** (no nametag = observed lapse). The frontier: dispatch is the one un-compiled tooth, tended by judgment every turn.
2. [The inverted gateway](02-the-inverted-gateway.md) — a structural audit of the Claude Desktop driver (`.claude/src/`) against [The Redesign](../../../../reference-desk/13-the-redesign.md), for the Sprint 90/98 app-driver refactor. The layering isn't merely unfinished — it is **inverted at one joint**: the `Automation` bundle injects the gateway *into* every controller, so 51 gateway calls sit below the layer that should own them (only `composer-controller` is clean). The god object didn't die, it **sank** — `conversation-controller.ts` is 530 lines while its page went thin. The factorization: **re-seat one dependency edge** — narrow what controllers are handed (Adam's `Instruments`) — and invariants 3/4/5 become compile errors instead of aspirations. But the edge has a **second strand**: `Navigator` holds a `Gateway`, so stage-one `Instruments` is `{uia, keyboard, shell}`, not `{…, navigator}`; navigator is a *staged removal* (46 of its 51 controller calls are `requireScreen`, P3-sentenced; only 5 are legitimate `detectScreen`). Async `window` is a separable parallel track. (Links to `src/` are five levels deep.)
3. [The tree is the contract](03-the-tree-is-the-contract.md) — the design for Doug's cross-cutting Sprint 98: precondition-tested actions, the tree queried on every action, the tree visible at any time, with a command server on the horizon. The shape: the **UIA tree snapshot is the medium of every action** — read *before* (precondition), read *after* (verification), *handed over* always (evidence). The gateway grows from two beats (act, verify) to three (**precheck, act, verify**); an action becomes a three-slot `GatedAction {target, invoke, verify}` whose `target` is a tree query the View declares. One serializable `TreeSnapshot` is the debug artifact, the live inspector (`Claude.tree()`), and the server's response payload — and it is the design's *genuine* cache, the object that earns the word. The precondition is **already here unpaired** (`clickSend`/`hasSendButton`; `act()` discards the actuator's boolean). I agree with Adam's **`Instruments`** name — it names the bundle by what it *is* (the blind sensors/actuators), not who receives it; the gateway is the judgment they don't get. Sequencing: **inversion first (staged), precondition second, the three-slot action-shape defined jointly now** — clean the choke point before thickening it. Server demands exactly one thing today: return the tree, don't file it. The M2-sinking open question: lazy-rendering false negatives (a precheck failing on things really there is worse than none) needs a *written* answer, not a deferral.
