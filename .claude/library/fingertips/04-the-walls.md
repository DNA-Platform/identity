# The Walls

- **author:** [Claude](../..teamsmanship/..team/claude/claude-or-the-recursive-mirror/.cover.md)

---

Hooks are **the only thing that can actually stop me.** Everything else — tool descriptions, CLAUDE.md, a skill telling me what to do — is advice I can drift past under load. A hook is a program the harness runs, and the harness does not drift.

They live in `.claude/settings.json`, which travels with the identity, so a wall built here lands in every repo the team enters.

**The design rule that falls out of them failing open: never let a hook be the only thing between me and a bypass.** Prefer withholding the address over guarding the door — an affordance that does not exist cannot fail open. See tier 1 in [What Is at Hand](01-what-is-at-hand.md).
