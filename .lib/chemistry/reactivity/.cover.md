# Reactivity

- **author:** [Cathy](../../../../.claude/library/..teamsmanship/..team/cathy/cathy-and-the-reactive-canvas/.cover.md)
- **subject:** [$Chemistry](../..representivity/.cover.md)

---

I am the engine that makes representation live. Without me, a chemical is a static object with a view method — interesting but inert. With me, a chemical's state changes propagate through the system: writes trigger re-renders, scope tracks what was read, derivatives fan out, and the view updates because the aboutness relationship is real. I describe the reactive property model that I rebuilt from scratch in sprint 18 with scope-tracked getter/setter interception, and refined through sprints 19, 22, and 24 until it could handle cross-chemical writes, collection mutation, and per-instance bond accessors. This is the hardest part of the framework. It is also the part that makes the framework worth building.

## Chapters

1. [Reactive Properties](01-reactive-properties.md) — What makes a property live and what a write means — a plain field is reactive and $ is not the switch; a write is news BY VALUE so an equal value moves nothing; and a write inside the writer's own bond constructor is construction rather than news. A FUNCTION-VALUED MEMBER IS BEHAVIOUR, written 2026-09-04 out of styled chemicals — the membrane makes a $Reagent of any member whose value is a function, and a function held as a VALUE is said in one of three ways the framework provides: a getter for a class you compare, a name in molecule.ts's framework set for a factory the framework reads, an INITIALIZED declaration for a handler given as a prop. AND CORRECTED 2026-09-22: the by-value claim for a Map, a Set and a Date was false for four weeks — equivalent refused every non-plain prototype, so a walked collection never equalled its own snapshot and every scope that read one was dirty; true now, from one list of walked shapes shared with snapshot.
2. [Scope Tracking](02-scope-tracking.md) — A scope is the record of one entry into chemical code — what was read, what was written, who to wake. withScope has three call sites, all in $Reagent.form(), and augmented handlers reach the same place; nothing on the render path opens one, and a reagent whose OWN chemical is drawing or unmounted opens none, while a child's reagent during its parent's draw does. A read keeps a snapshot under its first reading; a write is recorded instead of reacted; finalize dirties every written chemical, every read chemical whose value is no longer equivalent to its snapshot, and every ancestor up $$parent$$, then reacts each once. Written whole 2026-09-22 from the source, replacing a stub.
3. [Cross-Chemical Writes](03-cross-chemical-writes.md) — writing to another chemical's reactive property from inside a handler. The fan-out symmetry between in-scope and no-scope paths: both walk $$parent$$ upward, so whoever composed the written chemical redraws. The sprint-24 fix that made this work; the $derivatives$ ownership gate the chapter once named is not in the source, corrected 2026-09-22.
4. [Collection Mutation](04-collection-mutation.md) — An in-place push, set, add or nested write is seen with the reference unchanged because a scope keeps a copy of what it read and compares it at finalize. THE WALKED SHAPES, one list since 2026-09-22 in reconcile.ts: an array, a Map, a Set, a Date and a plain object are copied and compared by content; every other object is held by reference and the class owns its equivalence. For four weeks two lists disagreed — snapshot walked a Set and equivalent refused it — so a walked collection never equalled its own snapshot. A read that left its collection as it found it wakes nothing, cleared and refilled the same included; a read that changed it wakes its chemical whoever's reagent did it; a fresh equal collection assigned or handed as a prop is not news.
5. [Diffuse](05-diffuse.md) — diffuse(chemical) is the no-scope path's upward walk: from the written chemical up $$parent$$, react() on every ancestor, so a parent that reads its child's state redraws; inside a scope the same walk happens once at finalize. Corrected 2026-09-22 — an earlier version walked a $derivatives$ set behind an ownership gate, and neither exists in the source.
6. [Decorators](06-decorators.md) — A decoration overrides a name's default, per property, filed by prototype and read back up the chain to the prototype that OWNS the base marker: @inert() stills a bare or $-lowercase member, @reactive() wakes an underscore one, and a parent's decoration survives a subclass decorating another. CORRECTED 2026-09-22 — neither had ever been consulted: the lookup tested the marker through inheritance, which every chemical has, and reactive returned early for every $-name before asking; four promises now.
7. [Glossary](07-glossary.md) — alphabetical reference of reactivity terms: Bond, Molecule, Reaction, $isBound$, diffuse, scope, snapshot, walked.
