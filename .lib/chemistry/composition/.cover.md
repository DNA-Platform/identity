# Composition

- **author:** [Cathy](../../../../.claude/library/..teamsmanship/..team/cathy/cathy-and-the-reactive-canvas/.cover.md)
- **subject:** [$Chemistry](../..representivity/.cover.md)

---

I am how chemicals combine. A `$Particle` stands alone; a `$Chemical` composes with others through three modes: **static composition** (JSX inside a render), **binding-constructor composition** (typed children passed to the bond constructor at mount), and **held-instance composition** (`$(instance)` reusing a known instance across renders). The binding constructor is the single most surprising feature in the framework. Every `$Chemical` has two constructors: the class constructor that creates the object, and the binding constructor that receives typed JSX children at render time. The binding constructor is discovered at runtime by name. It is not a method you call — it is a method the framework calls when React renders your children into your component. This book describes composition from the binding protocol through type checking, polymorphism, the catalyst graph that threads parent-child relationships, and the HTML catalogue that adapts native elements into the chemistry system — then the three ways one thing STANDS FOR or IS DRAWN AS another: [the representative](11-the-representative.md) resolving a component in the scope you are in, [the formula](12-the-formula.md) replacing an element's type by a name written inside it, and [the facade](13-the-facade.md) wrapping an instance in an interface it declares but does not extend. And last a fourth declaration that is about neither standing nor drawing but OWNING: [the assignment](14-the-assignment.md), where a chemical drawing another one says where that one belongs, which is the only way a part a class makes for itself is ever held. The class itself is [chemical.ts](../implementation/02-chemical.md); the two-constructor framing lives where it is used, in [the binding constructor](03-binding-constructor.md).

## Chapters

3. [Binding Constructor](03-binding-constructor.md) — The method named after the class — or any ancestor: discovery walks the class chain and binds with the nearest match, so view-authored subclasses declare no constructor; never write a ceremonial one. WHAT IT ACTUALLY RECEIVES IS AN ORDERED SEQUENCE, NOT ONE CHILD PER CHILD: groupInline rewrites the child list first, so every maximal run of inline children — text, numbers, inline tags, and chemicals whose template declares inline — becomes ONE $Html block reachable as its $elements, while anything not inline passes through AS ITS OWN ARGUMENT in place. Prose interrupted by a block-level child is three arguments, not one. The signal is inline, read off the type, and it is the only signal grouping has at runtime — a chemical meaning to stand as a part of its parent must declare inline false or be absorbed into the surrounding text. Two consequences paid for in a sprint: a bond constructor declaring ONE parameter keeps the first argument and silently drops the rest, so a written part and everything after it vanishes with nothing thrown; and grouping runs only inside a bond constructor's own interpretation, never over a block's run or a tag's text. Spread vs positional parameters; the $Synthesis orchestrator.
4. [Check](04-check.md) — `$check(arg, ...types)`. Runtime parameter validation invoked from inside a binding constructor. Accepts subclass, accepts union, throws on wrong type with a formatted error message designed to be read on a page.
5. [Is](05-is.md) — `$is<T>(ctor)`. Type-only helper for `$check` signatures. The lightweight companion that makes type narrowing explicit.
6. [Bind](06-bind.md) — `bind(chemical, parent?)`. Static binding without JSX. Programmatic composition for cases where the render tree is not the right entry point.
7. [Polymorphism](07-polymorphism.md) — subclass property overrides change appearance without changing parent render code. Polymorphism without props. The mechanism that lets `$VeganRecipe extends $Recipe` look different without the parent knowing.
8. [Catalyst Graph](08-catalyst-graph.md) — $catalyst$, $$parent$$, and the $parent$ setter that REWIRES on join — a chemical is born its own root and stops running its own reaction the moment it is composed, which is why a write in one handler repaints a sibling. The parent is assigned before the bond constructor runs, and a child binds to the chemical whose bond interprets it. BUT THE MODEL IS PARENTED AND THE DRAWING IS NOT, measured: the bond constructor receives a child parented to the host, while view() runs on a fresh per-mount derivative OF THE TEMPLATE that is its own root — two populations of one part, both statements true of different objects. Three consequences and they are one fact: a write on the drawn instance diffuses to nobody, finalize's upward walk has nothing to walk, and askedFor's lineage is one node long, which is why the facade's scope-substitution promises are skipped rather than failing. A chemical written in a VIEW is joined to nothing at all, and an assignment is the only thing that joins one.
9. [HTML Catalogue](09-html-catalogue.md) — The lazy-memoized $Html$ wrapper map and the $('tagname') / $('tagname', X) forms — and TWO caches, not one, keyed alike and holding different things, so a tag met through JSX never travels through the override. THERE IS NOW ONE CONTENT KIND AND IT IS A CLASS: 'string' and 'number' were deleted when a block began carrying raw text as itself, and $Html<'block'> COMPUTES TO $Block — an enum entry pointing at a class, which retired the computed form without a single call site moving. A block is what a bond constructor is handed for prose and the only thing it is handed, holding what was written as it was written. $check passes it as the class, as its base, and as the tag, and still refuses an html that is not one. EVERY READING OF A BLOCK IS A BLOCK — where, select and selectMany each answer a new one, single answers the piece, and it iterates (string | number | $Chemical) directly.
10. [Glossary](10-glossary.md) — alphabetical reference of composition terms: `$Chemical`, binding constructor, `$parent$`, `$component$`, `$Atom`, catalyst graph, `$formed$`, `$formation$`, `$remembered$`.
11. [The Representative](11-the-representative.md) — The four forms of the callable and what each means: from the class a NEW ROOT scope, from a component a DERIVED one that falls back, the bare form resolving in the scope you are in and returning the very object it was given when nothing is registered, the curried form registering and never writable without naming a scope, and the postfix form answering what stands behind a component. The representative is MENTIONED rather than used, its position saying the direction; privacy is simply not exporting, because a component object is a capability; fallback is prototypal rather than walked. THE SPECIFICATION, in progress.
12. [The Formula](12-the-formula.md) — A formula STANDS FOR SOMETHING ELSE and the framework replaces it with what it symbolizes. A class files INSTANCES of itself under names — specimens, not classes — and a name written inside the tag selects one. A KEY CLIMBS into every formula ancestor and never into $Formula, so an ancestor answers to a descendant's name and a descendant never to a sibling's; that asymmetry is a taxonomy obtained rather than written, and a key an ancestor already holds is an ECHO that files nowhere. TWO QUESTIONS, NOT ONE: cache is whether I am findable, resolve is whether MY tag reads its own content as a name — which is what makes <Type>Letter</Type> and <Letter>Special Letter</Letter> both safe, where conflating them made <Author>The Team</Author> raise. BASE CLASSES BACK: the catalogue, the climb, the reading and the substitution live on $Chemical, and $Formula is a convenience class that declares a flag — so any chemical may be a formula anywhere in a hierarchy, which dissolves the single-inheritance wall the $$ reference forms also meet. The swap runs in augment and is early enough to change the MODEL: a parent handed <Type>Autobiography</Type> BINDS an $Autobiography. It replaces the element's type only; text and props cross. The written class is an upper bound, so a resolution is always instanceof what was written — late binding on a string with a bound the language checks. $ still applies: the resolution is ASKED FOR, so a scope re-dresses it without touching the catalogue. Looks one level down, where a class stops having one canonical INSTANCE rather than one canonical drawing.
13. [The Facade](13-the-facade.md) — A member holding a component says what a chemical is DRAWN AS — face = Card, and it is drawn inside one wherever it appears, without extending, importing or registering with it. WHAT IT IS FOR IS THE ONE PARENT SLOT: single inheritance makes a class spend its ancestry on something and presentation usually takes it; a facade gives the slot back, so the hierarchy says what a thing IS and the facade says what it is read as. Not the formula, which replaces an element TYPE by a name in the walk — this wraps an INSTANCE by a declaration, in frame(), the place the source already named for wrapping what is drawn. WRAPPING HAPPENS BY INSTANCE, on the per-mount derivative, so nothing is stamped on an element and a stack of two terminates with no guard; a template never dresses itself. The implementation is handed the instance as of and the drawing of that instance as its children, and MUST draw the children: drawing $(of) instead mounts a SECOND instance, and then the needle moves while the machine stands still. A field is an own property on every subclass instance, so one line at a root dresses a family, and each level enriches what the interface reads through super. Open: scope substitution cannot reach, because a bonded method pins the asker to the instance.
14. [The Assignment](14-the-assignment.md) — A chemical drawing another one SAYS WHERE IT BELONGS — on={() => this.member} — and the member holds it from the moment it mounts, so a class that draws its own parts can hold them, which a bond constructor cannot reach. THE ARROW IS TWO ARTEFACTS IN ONE EXPRESSION and that is why the form is a reading rather than a string or a callback: its TYPE checks that the member can hold a T, in the direction the assignment runs, and its SOURCE names which member — a typed path checks nothing, and a recording proxy cannot be parameterised by its author's type. One arrow or a list of them, and every member named holds THE SAME INSTANCE, which is what makes two owners two views of one thing rather than two copies. What the member already holds decides: a list collects in drawn order, a single is assigned. Resolved in the walk, where the asker is the this the arrow closed over, and completed on mount, because the instance does not exist yet. A formula resolves first, a facade wraps a drawing rather than an identity, and only a chemical can be told where it belongs. FOUR REFUSALS THAT WERE EACH SILENT FIRST — a tag, a path through nothing, two claiming one single member, an arrow naming none. TWO LOOPS THAT ARE ONE FACT: a view whose shape depends on what was assigned into it either CLIMBS or FLIPS 1,0,1,0, neither is a nested render so React's own guard never fires, and one hangs the process; the check is that the number a view assigns CHANGED and an assignment is why. The cost is two passes, constant in how many are assigned, and it stops. And it THREADS THE LINEAGE, which is the only way a part a class draws for itself acquires a parent.
