# Composition

- **author:** [Cathy](../../../../.claude/library/..teamsmanship/..team/cathy/cathy-and-the-reactive-canvas/.cover.md)
- **subject:** [$Chemistry](../..representivity/.cover.md)

---

I am how chemicals combine. A `$Particle` stands alone; a `$Chemical` composes with others through three modes: **static composition** (JSX inside a render), **binding-constructor composition** (typed children passed to the bond constructor at mount), and **held-instance composition** (`$(instance)` reusing a known instance across renders). The binding constructor is the single most surprising feature in the framework. Every `$Chemical` has two constructors: the class constructor that creates the object, and the binding constructor that receives typed JSX children at render time. The binding constructor is discovered at runtime by name. It is not a method you call — it is a method the framework calls when React renders your children into your component. This book describes composition from the binding protocol through type checking, polymorphism, the catalyst graph that threads parent-child relationships, and the HTML catalogue that adapts native elements into the chemistry system. The class itself is [chemical.ts](../implementation/02-chemical.md); the two-constructor framing lives where it is used, in [the binding constructor](03-binding-constructor.md).

## Chapters

3. [Binding Constructor](03-binding-constructor.md) — The method named after the class — or any ancestor: discovery walks the class chain and binds with the nearest match, so view-authored subclasses declare no constructor; never write a ceremonial one. WHAT IT ACTUALLY RECEIVES IS AN ORDERED SEQUENCE, NOT ONE CHILD PER CHILD: groupInline rewrites the child list first, so every maximal run of inline children — text, numbers, inline tags, and chemicals whose template declares inline — becomes ONE $Html block reachable as its $elements, while anything not inline passes through AS ITS OWN ARGUMENT in place. Prose interrupted by a block-level child is three arguments, not one. The signal is inline, read off the type, and it is the only signal grouping has at runtime — a chemical meaning to stand as a part of its parent must declare inline false or be absorbed into the surrounding text. Two consequences paid for in a sprint: a bond constructor declaring ONE parameter keeps the first argument and silently drops the rest, so a written part and everything after it vanishes with nothing thrown; and grouping runs only inside a bond constructor's own interpretation, never over a block's run or a tag's text. Spread vs positional parameters; the $Synthesis orchestrator.
4. [Check](04-check.md) — `$check(arg, ...types)`. Runtime parameter validation invoked from inside a binding constructor. Accepts subclass, accepts union, throws on wrong type with a formatted error message designed to be read on a page.
5. [Is](05-is.md) — `$is<T>(ctor)`. Type-only helper for `$check` signatures. The lightweight companion that makes type narrowing explicit.
6. [Bind](06-bind.md) — `bind(chemical, parent?)`. Static binding without JSX. Programmatic composition for cases where the render tree is not the right entry point.
7. [Polymorphism](07-polymorphism.md) — subclass property overrides change appearance without changing parent render code. Polymorphism without props. The mechanism that lets `$VeganRecipe extends $Recipe` look different without the parent knowing.
8. [Catalyst Graph](08-catalyst-graph.md) — `$catalyst$`, `$$parent$$`, and the `$parent$` setter that REWIRES on join — a chemical is born its own root and stops running its own reaction the moment it is composed, which is why a write in one handler repaints a sibling. The parent is assigned before the bond constructor runs, and a child binds to the chemical whose bond interprets it.
9. [HTML Catalogue](09-html-catalogue.md) — the lazy-memoized `$Html$` wrapper map. The `$('tagname')` and `$('tagname', X)` forms. How native HTML elements enter the chemistry system as adapted chemicals.
10. [Glossary](10-glossary.md) — alphabetical reference of composition terms: `$Chemical`, binding constructor, `$parent$`, `$component$`, `$Atom`, catalyst graph, `$formed$`, `$formation$`, `$remembered$`.
11. [The Representative](11-the-representative.md) — The four forms of the callable and what each means: from the class a NEW ROOT scope, from a component a DERIVED one that falls back, the bare form resolving in the scope you are in and returning the very object it was given when nothing is registered, the curried form registering and never writable without naming a scope, and the postfix form answering what stands behind a component. The representative is MENTIONED rather than used, its position saying the direction; privacy is simply not exporting, because a component object is a capability; fallback is prototypal rather than walked.
