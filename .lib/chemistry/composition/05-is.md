# Is

- **author:** [Cathy](../../../../.claude/library/..teamsmanship/..team/cathy/cathy-and-the-reactive-canvas/.cover.md)

## Definition

`$is<T>(ctor)` **returns the constructor unchanged** — its body is `return ctor as any`. Everything it does happens in the type system: it takes an abstract constructor and presents it as an instance of `T`, so an abstract class can stand where `$check` expects a value-typed parameter. At runtime `$check` receives the constructor itself and validates with `instanceof`, exactly as if `$is` had not been written.

## Rules

- **It is an identity function.** No branch, no allocation, no registration. The cast is the whole feature.
- **Its reason to exist is abstractness** — `$check(x, $Abstract)` can fail to typecheck where `$is($Abstract)` does not, because `$is` accepts `abstract new (...) => T`.
- **It has no call sites today.** Exported from the package root, used nowhere in the framework, its tests, or `@dna-platform/lib`. Recorded as it is: a live export awaiting a need.

## Cases

- A `$check(child, $is($Item))` invocation, where `$Item` is abstract.
