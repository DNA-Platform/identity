The cataloguing book for the $Chemistry branch library. $Chemistry is about representation — reactive state that stands for something beyond itself. This page is also the **reading order**: the books run shallow to deep, the way you learn any system — the contract you write against, then the mechanisms beneath it, then the source, with the proof alongside. Read them in sequence to learn the framework; take the **shortcut** inside a paragraph — a link straight to the chapter that answers the common question — when you already know what you need. This is the [synopsis architecture](../../bookkeeping/09-on-synopsis.md) at work: answer at the shallowest layer, open a chapter only when it can't.

## The reading order

### [Authorship](../authorship/.cover.md) — the contract you write against
Start here to *use* $Chemistry. A chemical is a class; fields are state; `view()` returns JSX; mutation re-renders — no `setState`, no hooks, no dependency arrays. The whole promise is one chapter, the [reactivity contract](../authorship/04-the-reactivity-contract.md) — read it and you can write chemicals. Descend into the mechanism books only when the contract's edges bite.

### [Particle](../particle/.cover.md) — the base every renderable inherits
Identity, lifecycle, per-mount derivation, and the single render path: an instance becomes a Component through [`$lift`](../particle/04-lift.md), and `frame()` wraps `view()`. Read when Layer-0 usage isn't enough and you need to know how a chemical becomes a component.

### [Reactivity](../reactivity/.cover.md) — how a write wakes the view
The scope snapshots each read and, on finalize, re-renders any chemical whose snapshot changed — so in-place mutation reacts *inside a method or handler*, and there are no reactive collections; the diff catches it. Read when a `$`-field isn't updating, or for cross-chemical fan-out (`diffuse`).

### [Composition](../composition/.cover.md) — how chemicals contain particles
The binding constructor parses typed JSX children into a chemical's parts; a tag / `String` / `Number` / class parameter resolves through the [HTML type-and-catalogue](../composition/09-html-catalogue.md) to the value that `$check` validates. Read the moment you meet a `$Name(...)` bond constructor.

### [Implementation](../implementation/.cover.md) — the source, file by file
Primary source, narrated per module across `package/src/`. Read when a mechanism book points you at the code and you want the code explained beside it.

### [Epistemology](../epistemology/.cover.md) & [Testing](../testing/.cover.md) — how we know it works
The Lab, the caveats, the open questions — and the suite as specification, where each test is a claim about what $Chemistry *is*, provable by running it. Read a test when you doubt a sentence.

### [Glossary](01-glossary.md) & [Representivity](.cover.md)
Every term, one line, linked to where it is defined — and this catalogue, listing itself.
