The design record of the Inexplicable Phenomena repository — how `@dna-platform/lib` is used to build ways of *viewing* the repo's content. Where [The Semantics of Books](../the-semantics-of-books/.cover.md) derives the object model from its source conversation, this book tracks the **design decisions of the repo itself**: what gets built on the classes, which prior work is extended rather than reinvented, and what each surface must do. Notes first, designs when settled — a chapter here is allowed to be a working notebook, kept honest by citing where each idea came from.

## Chapters

1. [The Notes We Already Took](01-the-notes-we-already-took.md) — gathers the prior design notes this book extends: Sprint 43's resource record, the `.archive/` markdown-plus-LaTeX converter and its spec, the twelve prototypal library classes written once already, and the eleven SRT prototypes in the export. The starting shelf, so nobody repeats the archaeology.
2. [Markdown with LaTeX on the Composition Classes](02-markdown-with-latex.md) — the design notes for the sprint's stated goal: a section that can be written in markdown with LaTeX, built on the composition classes with the archive's converter stack (marked + KaTeX + highlight.js). The model, the first spike, and the open questions.
3. [Navigation for the Lab](03-navigation-for-the-lab.md) — the Lab's navigation made flexible enough for what's coming: case sections beside full-page designs, mobile-capable per the prototypes' responsive principle — the thing stays, the about-the-thing collapses.
