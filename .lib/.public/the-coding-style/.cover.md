A refactor finds the ruling here before it undoes one.

## Chapters

1. [The Unit of Code](01-the-unit-of-code.md) — Three programs, three answers to what one piece of code is — and one rule that decides all three: THE UNIT OF CODE IS WHATEVER THAT PROGRAM STATES ITS INVARIANTS OVER. A program's file boundaries should fall where its promises fall, because a promise that spans two files is a promise neither file can keep, and the way that failure arrives is always the same.
2. [The Order of a Class](02-the-order-of-a-class.md) — The member order inside a class, given by Doug four times in one sitting and quoted rather than paraphrased because paraphrase is what kept getting it wrong. AMENDED 2026-08-30, when he gave it again and it had changed. THE ORDER IS NOW SEVEN GROUPS: fields, then properties, then the bond constructor, then the constructor, then methods, then protected methods, then private methods.
3. [The Coding Style](03-the-coding-style.md) — THE INDEX OF EVERY RULE IN FORCE, so a refactor finds the ruling before it undoes one — each row saying what a document RULES and the day the ruling was given. Carries the four chapters on how code here is written, where a class lives, the $-fetch and timing law, the spec convention, WE DO NOT INNOVATE, NO INVENTED LANGUAGE with its struck-word table, what is never okay, the seen gate, the comment lifecycle, NO PERSPECTIVES, styling, the drawing conventions and the minifier caution. THE ANCHORS ARE THREE: this is the public library; it is closed under books; and — given 2026-09-13 — BOOK IS LAYOUT, CHAPTERS ARE LOGICAL PARTS, the page's arrangement against the page's meaning, which Doug names the essence of the framework and which is the test for where any new thing goes.
4. [The Closeness Rule](04-the-closeness-rule.md) — The law the other style chapters are expressions of: PROXIMITY encodes relatedness, SIZE encodes relevance inverted, the order always wins, art operates only where the convention is silent. The four instruments — ordering, stacking, compactness (bracketless one-liners, guards on one line, housekeeping fors small), paragraphs in code with extraction earned by polymorphism alone. What the law forbids: readability blank lines, doubles, moved members, guards drawn as branches, comments.
5. [The Spelling of a Kind](05-the-spelling-of-a-kind.md) — How a kind is spelled, in the order a file declares them: the class, the type with its name and cache as one act, the bond (super FIRST so a carried type wins, then a default through $check with the make marker), formula = 'new' only where a kind must not answer to names its siblings filed…
6. [The Shape of TSX](06-the-shape-of-tsx.md) — HOW TSX IS LAID OUT, HOW A COMPONENT IS NAMED, AND WHAT $ IS FOR — written 2026-09-04 because the branch had rules for the layout of a class and none for TSX, which is most of the code.
7. [What Natural Means](07-what-natural-means.md) — The third thing the other two lean on, and the one that was never written down: Doug asks for natural constantly and ceremony and ugly-member both MEAN departure from the natural shape, so neither reading works if that shape is a matter of taste. Three tests, all three or it is not natural: it says the thing in the DOMAIN's own words (say it out loud - a name that needs explaining is a name that is wrong, and Colophon, Masthead, ladder, law, rail, mint were all precise and all struck); it ASKS where it had been deriving, storing, or deciding by position or by name (the tell is a ROSTER - any list of names, positions or exceptions inside a rule is a concept nobody has named yet); and it uses the mechanism already there, because if you need a NEW MEMBER to say it you are describing a feature the framework should have. HOW YOU KNOW YOU FOUND IT IS A NUMBER: a natural change SUBTRACTS - Book 214 lines to 65, 62 hand-written type names deleted, 24 instanceof to 0, 57 bond constructors absorbed, 11 view() overrides to 1, 75 element selectors to 15. A change that only adds is one to be suspicious of. Six shapes of unnatural with a real one behind each, the coherence test for what the rules miss, and the warning that naturalness is not a licence to restructure: friction is the design speaking, and three formats died in two days against a wrapper that should have worked. AND THE WARNING'S OTHER FACE, from Sprint 59: when a design built to Doug's words fails its own promise, HALT and re-hear the words; never go into the framework to make the reading work — a 47/42-line refactor of $Synthesis was rolled back and the re-heard design needed no chemistry line.
