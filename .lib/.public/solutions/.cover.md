[Projection](../projection/.cover.md) indexes the same work by time; this book indexes it by problem, and neither answers the other's question. Every entry below opens with the **symptom** — the error text, the wrong value, the visible behaviour — because a reader arrives holding one of those and not a diagnosis. Each chapter carries a keyword line for grep, drawn from the vocabulary below.

## The keyword vocabulary

Grow this list only when a genuinely new class appears, and grow it here so the next writer sees it.

**Surfaces:** `framework` (chemistry itself) · `model` (`@dna-platform/lib`) · `demo` (the app) · `tooling` (compilers, validators, sync) · `library` (books and covers) · `sync` (identity and branches)

**Mechanism classes:** `stale-artifact` (a compiled or derived thing that outlived its source) · `missing-parent` (a chemical built outside chemistry) · `render-loop` (mutation during render) · `wrong-altitude` (a decision made at the wrong level) · `unproven-deletion` (a member removed without proving it dead) · `silent-default` (a guard or flag that did nothing) · `lifted-class` (code reasoning about the class as written, where the object was built from a class the framework made) · `rebind` (prop binding re-running over an already-built instance's held state) · `absent-case` (a gate ran correctly over content or timing that could not exercise the defect) · `narrowed-declaration` (a subclass narrowed what its base widened, and the narrowing travelled the wrong way) · `assumed-environment` (an artifact depending on something the repository does not contain and does not name) · `mechanical-edit` (a change made by matching a pattern where the meaning had to be read)

[The checkpoint that compared a number to itself](18-the-checkpoint-that-compared-a-number-to-itself.md) — **a driver checkpoint passed on its first run and every run after, and was reported to Doug as evidence — 'the model reads at every altitude and the count cannot move, 260 words as paragraphs, 260 as words' — and there was nothing that could have failed it.** Doug read the sentence and asked what it meant, which is how it was caught. TWO WALKS IS NECESSARY AND NOT SUFFICIENT: a comparison spanning a region the sides are designed to differ in carries a built-in error term it never subtracts, so it cannot be green honestly — it is green only while something else is wrong by the same amount, which makes its green a report about a SECOND defect. And the tell is worth more than the rule: A PROMISE THAT GOES RED WHEN YOU FIX SOMETHING WAS MEASURING THE DEFECT — the first question is not what broke, it is what the assertion had been true about.
