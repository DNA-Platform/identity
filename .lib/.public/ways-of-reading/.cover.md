The first design notes of the repository — how its content is VIEWED. The notes the team already had, markdown with LaTeX on the composition classes, the Lab's navigation, the view catalogue that makes the book the fundamental website, the live library, and the back of every page. These are the earliest chapters of the design record and they read as notes: ideas first, cited to where they came from, designs only where one settled.

*Split out of the single design book on 2026-09-11 at Doug's direction — "26 chapters is way more than you even read in a whole catchup session" — with every chapter's entry carried over byte for byte and renumbered.*

## Chapters

1. [The Notes We Already Took](01-the-notes-we-already-took.md) — The prior notes this book extends: Sprint 43 resources, the archive markdown-plus-LaTeX converter, the twelve prototypal library classes, the eleven SRT prototypes.
2. [Markdown with LaTeX on the Composition Classes](02-markdown-with-latex.md) — Markdown-with-LaTeX built into the object model — `$Latex` inline, `$Markdown` an authoring adapter that renders composition objects through eval.
3. [Navigation for the Lab](03-navigation-for-the-lab.md) — The Lab navigation: case sections beside full-page designs, mobile-capable — the thing stays, the about-the-thing collapses.
4. [Ways of Reading](04-ways-of-reading.md) — The view catalogue: the book as the fundamental website, view patterns decomposed into three shipped moves — lens, reading, arrangement; a book is an evolvable authored structure, and views multiply claims. THREE SPECIFICATIONS FOR EVERY VIEW now: identity through change, views multiply claims, and — added out of The Parse — A VIEW READS, IT DOES NOT RE-DERIVE.
5. [The Live Library](05-the-live-library.md) — Doug's aside of 2026-08-22, written down as an aside and not as a plan, because a constraint that arrives after a decision costs more than one written down before it. Yes to both facts: this is a GitHub repository and the application is served by GitHub Pages, at a repository path today and at a domain root the day one is pointed here.
6. [The Back of the Page](06-the-back-of-the-page.md) — Doug's, 2026-08-22: THERE IS A BACK TO EVERY PAGE — count the sections, the paragraphs, the words, the subject spine, the attributes, and that is a COMPLETELY DIFFERENT VIEW OF THE SAME PAGE OR BOOK. A view the framework does not have and needs nothing new to build, which is the fact worth writing down because it is the test of whether a thing is really a view.
