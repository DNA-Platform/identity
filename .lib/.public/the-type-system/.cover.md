## Chapters

1. [What Carries Over](01-what-carries-over.md) — Doug asked the team what changes between the versions and what stays, so it was measured rather than remembered: v1 is 51 files, 3,498 lines, 46 classes and 54 published exports; v2 is 16 files, 491 lines, 23 classes of which eleven are $TypeOfX — twelve substantive — and it publishes NOTHING. Eleven words appear in both and thirty-five v1 classes have no counterpart.
2. [The Type and the Instance](02-the-type-and-the-instance.md) — The type holds the meaning and the instance holds the data, so meaning moves without subclassing — the type is a factory for its class, freeing the single inheritance slot. One question decides where a member goes; the corollaries were learned expensively — a rule is a method not a property, rules run base-first deduped, there is one specification and it is the type's.
3. [Shells Over Types](03-shells-over-types.md) — RULED 2026-09-02 and obeyed: everything derives from Writing, base classes stay free for the end user, kinds are TYPES and the type grants the powers, so a canonical class is a SHELL — visibly one. The test for any new class: name what it does that its type could not confer.
4. [The Interface Type System](04-the-interface-type-system.md) — The design of the second $Writing, written while it was being built with Doug: the four purposes in his words (any part replaceable, $Writing easy to subclass by FOLDING IN types, specifications so types can be CAUSAL, and the check run statically at build — 'we're making a little compiled language'), and the sentence the whole thing turns on.
5. [What We Believe](05-what-we-believe.md) — The principles in force, each one Doug ruled and each followed by what it cost in code — why any of it (any part replaceable, $Writing easy to subclass, types causal, checked at build), the four-declaration file, the class as a shell the type carries the complexity for, the seven levels, the drawing, the book and its apparatus, the machinery, and what the type system will not let us have, measured rather than argued. UPDATED 2026-09-08: P23 is superseded — every frame() override is gone from src and a kind writes its own element in print(content), one line, the span surviving only for a sentence, a word and a letter because HTML has no element for those. And P24 is now the uniformity law, given by Doug as "it is at the level of bug to add print and not have it used uniformly": an audit found fourteen kinds using the seam, eleven overriding view instead, and twenty-nine using neither and drawing a bare span — nine of which said by TYPE what they were and drew nothing like it, because print is inherited by CLASS while the hierarchy rides the TYPE, which is P11 s shadow and which no compiler, promise or rule will mention. The repair needed no machinery and span fell to one per page.
6. [Polymorphic Limiting](06-polymorphic-limiting.md) — Structure is a property, an assumption is present, and unverified means unassumed. The smell they name: a subclass needing what the base does not offer and reaching for a member to hold it, which proves a framework mechanism is missing or was not found, and is not fixed by widening the base either. AND ITS SECOND FACE, measured 2026-09-09: the member moved to a utility with the receiver demoted to an argument, which looks like good engineering and is the same defect hidden better. 17 of Reflection's 22 methods are methods of Writing or Type living outside both, and the module cycle that explains the registry was mistaken for permission to move the methods.
7. [The Composition Type Hierarchy](07-the-composition-type-hierarchy.md) — DOUG'S NAME FOR WHAT REPLACED below(), ruled 2026-09-11: there are six levels of text and two of the library, reflection memorizes both ladders once (handed from the book's register), the rung below a kind is read by type inheritance up the class chain, and a specialisation is a registration in chemistry's own words, for A a B is a C: a list's copy becomes items and a contents' parts become rows with no method on any type. No reflection happens outside reflection. Points at Reflection, Composition.parts(), the Representative, the Levels of Writing and the sprint that ruled it.
8. [The Cover Is a Cover](08-the-cover-is-a-cover.md) — Why a team was fired on 2026-09-13, written at Doug's instruction the same hour, and carrying HIS OWN statement of the cause above the session's: the synopsis and the table of contents were DISSOLVED to buy a layout rather than the layout being learned. Beneath it the two counts the session named itself — a cover styled from the frame's selectors after three sprints of deferring the typing he had ruled by name, and a shape of its own substituted for the design he gave where the book holds a section. Carries the rules that follow: a design Doug gives is built as given, a basic template is typed before it is styled, an owed kind makes the next plan not implementation-ready, a rule with an exception list is a wart the plan wrote, and the next question to him is about what he has already ruled. And the standing one: an apparatus of the book is never dissolved to make a layout work.
