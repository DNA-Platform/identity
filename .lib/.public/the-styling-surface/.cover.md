**Everything a styler meets when they dress a library written on `.public`, and nothing else.** The base ships no style: what it ships is *marks* — a class on every element saying what the writing is or what was said of it — and the elements and attributes beneath them. A library's theme is one styled component written against the marks on one side; a library's Formats are styled components that own clusters of marks on the other. This book is the whole of that surface, read from the code, so that a theme is written with the roster open and not from memory of a page.

The first chapter is one side, [the policy's](../projection/102-sprint-97--formats-are-the-unit-of-styled-components.md#the-policy) *dressed by mark in the theme*: every class a library's base theme addresses, what element wears it, who puts it there and when. The second is the other side, *replaced by subclass*: the clusters of classes each Format owns, what the base's template says of them and what a library overrides. The third is what is on the page and is not a class — attributes, custom properties, foreign markup, generated hashes — and which of it a rule may name. [What Is Marked and What Is Replaced](../writing-a-book/06-what-is-marked-and-what-is-replaced.md) is the same roster from the classes' side, by TypeScript class; this book is from the page's side, by CSS class.

## Chapters

1. [The Base Theme's Classes](01-the-base-themes-classes.md) — Every mark a library's theme dresses, in five tables: the seven levels, the types of sentence and letter, the words that read the compiler's forms, the figures and the typeset, and the fundamental annotations' marks; each with the element that wears it, the class that puts it there and the moment — the bond, each define, the bind — the layers that stand between it and its parent, and the one thing a theme usually says of it. Then the rules of writing against them: by descendant through `pd-container`, never by child or sibling; by mark, never by element type, but for the foreign elements the base does not mark; a state as a mark, a quantity as a value.
2. [The Clusters](02-the-clusters.md) — The classes each replaceable Format owns, one cluster per Format: Table's nine, List's three, Paginated's three, Cover's one and its header, TableOfContents' and its nav with Content's span, Synopsis', the biographies', the three basics' on their own elements; for each the element that wears each mark and when, what the base's template carries as the marks' meaning, what a library's subclass writes, and how it is put in place — registration on the book class, or import from the book file.
3. [What Is Not a Class](03-what-is-not-a-class.md) — The rest of the page: the attributes the framework writes — `id` from a Referent, `href` on an anchor, `hidden` on a parenthetical, `datetime` on a date, `data-line` on a numbered line, `src` and `alt` on a picture, `language-x` on a code element; the custom properties a library's values become on the theme's element; the foreign markup inside a mark — KaTeX's, the highlighter's, an inline svg — and its stylesheet; styled-components' generated classes, which a rule never names; and the layers, `pd-container`, which a rule crosses and never counts.
