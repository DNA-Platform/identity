The representation of things that are not quite writing: a file accompanying a chapter, inserted where the author writes a literal, `![[ code.tsx ]]`, or appended by an Append the author writes, and shown in the text by a Figure, the type of letter that interfaces it. Built 2026-09-28 in [Sprint 89](../projection/94-sprint-89--figures.md) for the code, pictures and prose a library keeps beside the chapters that document them — *"a library whose inside contains its own outside, at least in printed form."* The classes live in [`src/figures`](../../package/src/figures/), a folder that grows as figures are invented.

## Chapters

1. [Figure](02-figure.md) — FIGURE, written 2026-09-28 with Sprint 89: the letter that interfaces an append, named by identifier or by type as attributes, drawing the append's contents after the author's own or standing as its own literal, taking annotations as any letter does, throwing when it names an append its chapter lacks; the general form every figure grows from, and how a library writes a figure of its own.
2. [Code, Image, Document and Svg](03-code-image-document-and-svg.md) — Code, Image, Document and Svg, the four figures that ship, each from an appended file or from the author's own input: Code a letter whose own element is the pre, lit by highlight.js and numbered when asked; Image a picture by the append's address, lazy and decoded off the main thread; Document, since Sprint 125 on Doug's 'We need to be able to read it', a twin of Image for a PDF, an object at the append's address that the browser's own viewer shows on the page, a link to the address inside it for a browser with none, the binder serving the file by address as it serves a picture and the proof taking a link to a placed file as answered; Svg the markup inline. The default sheet's rule for each, a document as wide as the measure and as tall as a page of it; what the viewer loads, a document from the page's own origin drawn even headless and a file's cross-origin load not; four promises, each figure from an append and from input, the regression's document placed, unbundled and served as a PDF; the gates of 2026-09-28 and 2026-11-10.
