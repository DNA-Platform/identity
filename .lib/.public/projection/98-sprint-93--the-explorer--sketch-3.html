Chapter 2

The Theme

What the theme is

The one thing every book here shares. It is $LibraryTheme, a class under the framework's Theme; it sets the eight values a theme has, and in its define it extends the default sheet rather than replacing it, since the default comprehends every mark the framework puts on an element and mine adds the library's look on top of those same marks. Every rule reads the theme's values, so a book that overrides them keeps the look in another ink, which is what Libby does to go dark.

The helper every style reads through

The file opens with at, a small helper every style in this library uses to read a value: the property named on the theme the format stands inside. A book always has a theme, so the fallback it still carries is never reached; what it reads is the theme's variable.

The seven values the library sets

The class sets seven of the eight and leaves the size alone: Georgia, a longer leading, a wider measure, a warmer space, a dark ink, a warm paper and an oxblood link. Nothing else about the look is a value; everything else is a rule reading these.

2-the-theme.code.tsxlines 8–15
8export class $LibraryTheme extends $Theme {9    font = "Georgia, 'Times New Roman', serif";10    leading = '1.7';11    measure = '42rem';12    space = '1.25rem';13    ink = '#23262a';14    paper = '#faf8f4';15    link = '#5b2f2a';

Extending the sheet in its define

The sheet is extended and never replaced: $Define calls the base's, then reassigns the style to a selection of it, so every rule of the default stands and the library's are added after it and win where they meet.

One voice for every label

The kind labels, the parenthetical titles, the table's headings and its header row share one rule, small, uppercase, letter-spaced and faded, so a reader learns once what a label looks like. The label above a chapter's title is a counter, and the apparatus names itself.
