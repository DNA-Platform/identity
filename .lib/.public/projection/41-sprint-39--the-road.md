# <a id="the-styled-finding"></a>The styled finding — dress seats refuse the fetch

Sweeping every view and frame onto `const Asked = $(X)` broke 78 tests in one stroke, all with the same voice: *element type is invalid — got null.* The conviction is exact: our dresses are styled-components, styled-components are **forwardRef exotic objects** (`typeof === 'object'`, `$$typeof: Symbol(react.forward_ref)`), and chemistry's `$` walks its overloads — element, particle, plain function, chemical component, string, class — finds no branch for an exotic object, and answers **null** (`chemical.ts:1743`, "unrecognized arg — null is safer than re-entering JSX"). Every chemical seat took the fetch; every dress seat refused it. The sweep was reverted at the dress seats alone — dresses stand literal in JSX — and the whole chemical sweep held. **The Wave-0 question this mints: should dresses be DI-able at all?** If yes, chemistry's `wrapped()` must learn exotic objects — a chemistry change, his direct instruction only. If no, the law writes itself cleanly: *types are fetched, dresses are worn* — the fetch convention is for seats the scope may answer, and a dress is not one.

# <a id="styled-chemistry"></a>The styled-chemistry design, 2026-09-04 evening — brainstormed WITH Doug, nothing built

Doug's seed, verbatim: *"Can we just make a style=true tag for a chemical, and when that tag is true, the properties get compiled into a style component?"* and, refining: *"For the styled props, those can all be non-reactive as a convention except ones with $ in front... any chemical with true automatically does this."* The design that emerged, all states verified against source or probe except the compiler itself (~40 lines, unbuilt):

- **THE NAME IS HIS: "styled chemicals"** — *"and like normal we do $ and non $ props, but for styled chemicals (that's what we call this!) the non-$ props that are part of styled components are not reactive."*
- **The canonical example (Doug: "I like this one"), refined by him to `styled = true`:** a regular chemical, `styled = true`, `tag = 'main'`, CSS as camelCase fields; the framework compiles them into a styled component and lands it at **`[style]` — an exported SYMBOL seat** (his refinement: *"maybe export a symbol called style, so that [style] is the compiled component if anyone needs it"*), the same idiom as chemistry's `[cache]`. Compiled once per class, readable from any instance through the prototype. The escape hatch is the seat itself: Anchor and Prose (the folder's only two non-flat rules) occupy `[style]` with a hand-written styled component, and an occupied seat is used as-is — nothing compiles.
- **Reactive split, landing on EXISTING chemistry law** (bond.ts:51-66): bare names are reactive by default, `_` inert, `$`+lowercase "special" reactive. So `$background` is ALREADY the live spelling — and the compiler marks bare CSS-named fields inert via the same per-class registry `@inert()` uses. Baked properties cost nothing at runtime; `$`-properties restyle on write through the normal render subscription.
- **Detection**: strip a leading `$`, ask `'maxWidth' in element.style` — the browser's own property list; chemistry members never leak into CSS.
- **Polymorphism**: each class compiles only its own field contributions (bare-template diff, the reflection trick), extending the parent's styled component via `styled(Parent)` — JS inheritance becomes CSS cascade; subclasses re-bake single properties, change `$`-defaults, or occupy `[style]` outright. **PROMOTION IS RULED IN** — Doug: *"I love the $x and x thing. Yes allow promotion. That is powerful."* A subclass respells a baked `x` as `$x` and the property leaves the class stylesheet for the live props; the one rule: `$x` and `x` name the SAME CSS property, nearest class wins.
- **The wrap point is frame()** — the method called during render, already stamping pd- classes; style and frame become one system.
- **What it adds over styled-components alone**: property-grain inheritance, scope-level component swapping (probed: DI keys per component), state-bound styling without prop plumbing. **Costs**: a layer over styled-components, ~20 KB per chemical instance (page-level components only, never a chemical per word), the compiler.
- **THEMING, researched 2026-09-04 night at Doug's order** (*"Research because I want a designed feature for next sprint"*): the LIVE road is a getter — `get $background() { return this.theme.background }` — because `$`-properties are read per render, getters re-evaluate, and a theme chemical's reactive props subscribe across chemicals: one theme write repaints every styled chemical reading it. The STATIC road is bond assignment (`this.$background = theme.background`) — values copied at birth, no flow after. Theme delivery is DI: fetch at the seat, register per scope (`$(App, Theme)(DarkTheme)` — the probed mechanism); and chemistry's `$Atom` (atom.ts:9, the singleton whose every construction answers the one persisting template) is the theme's natural container. TWO EDGES FOR THE BUILD: (1) the `[style]` seat is a SYMBOL and the reactive law speaks string names (bond.ts:51) — a post-bond seat swap must ride a repaint (naturally the `$theme` write) or the addition tracks the seat explicitly — OPEN, verify at build; (2) a getter cannot override a base class FIELD of the same name (JS own-property shadowing) — the compiler prefers accessors per property, one rule.

## <a id="styled-chemicals-notes"></a>The chemistry-addition notes — NEXT SPRINT'S BUILD, rigorous, per Doug: "Do the handoff, write rigorous notes about this component as a serious chemistry addition"

**The contract.** RE-SEATED AT $PARTICLE, Doug 2026-09-04 night: *"put styled components on particle not chemical so its accessible on both... I want styled chemicals and styled particles both to be real."* VERIFIED it can be: `view()` and `frame()` are particle-level (particle.ts:125, 133), and so is the reactive machinery itself — "every particle carries a molecule" (particle.ts:96), $Particle.prototype called "the actual framework root for reactive entities" (:266). A styled particle is a regular particle that renders through a compiled styled component; a styled chemical is the same plus the DI tier. `styled = true` opts in; the compiled component lands at `[style]`, an exported symbol (the `[cache]` idiom); an occupied seat is used as-is and nothing compiles (the escape — Anchor's `&:hover`, Prose's `& &`). The wrap point is `frame()`, which already stamps the pd- classNames — style and frame become one system, `<Style className="pd-…">` around the view.

**What chemistry gains** (the serious addition): the `style` symbol export; the `styled` flag read at component resolution ON $PARTICLE — spelled as an overridable step, NEVER an if on the base (the override-don't-condition law applies to our own design); the compiler (~40 lines: chain walk → own-field diff → kebab CSS → styled(tag | Parent), cached per class in a WeakMap); auto-inerting of baked CSS names; the accessor-preference rule per property; optionally seat-tracking for post-bond `[style]` swaps. **What lib gains:** the encyclopedia rewritten as styled chemicals (14 components, 109 lines of CSS, only two non-flat); the `tag` seat (name is Doug's to give); themes as `$Atom` chemicals; the Styled.ts CJS/ESM shim contained in the one place that still touches styled-components — or deleted if the compiler ever emits its own stylesheet on the pd- rail (the recorded larger road).
