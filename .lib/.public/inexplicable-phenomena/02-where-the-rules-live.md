***Inexplicable phenomena wants rules of its own, and there are three places a rule can stand, each binding a different reader.*** Written 2026-11-05 as ideas, on Doug's word *"come up with some ideas for where we put that information too because we want IXP to have its own rules"*; nothing here is ruled.

## <a id="homes"></a>Three homes, by whom the rule binds

**This book, in the branch library at `library/.public/.lib`.** The team reads a branch library before the code beside it, so a rule here binds a teammate working in `library/`: which port, how a stub is written, that names and prose are Doug's. It costs nothing to add and is read by whoever catches up. It binds nobody who does not read it.

**The manual, Subjective Reference, at `library/.reference`.** The library's own specification, published with it, the code of its book, theme and faces standing beside the prose. A rule of what the library *is* belongs there — the eight words, the title form, the one autobiography — because the binder enforces those, and a rule the binder enforces is already written in the manual's code. It binds every bind, whether or not anyone reads it.

**A compiled rule under `.claude/rules/`, from a chapter of the team library.** Platform files are compiled from library content by [Environmentalism](../../../../.claude/library/..environmentalism/.cover.md) and never edited by hand; a rule that must stand in front of every session, read or not, is compiled there as `team.md` and `voice.md` are. Whether such a file can be scoped to `library/**` by a path line is to be verified before it is relied on.

**A fourth, for one subject.** A subject's own `.lib` beside its code, `library/<subject>/.public/.lib`, as chemistry has. A rule of chemistry's alone goes there and never to this book.

## <a id="division"></a>The division, as an idea

What the library is, the manual. How the team works in it, this book. What must bind unread, compiled. Start here; promote a rule to the manual when Doug writes it as the library's own; compile only what has proved it must be in front of every session.
