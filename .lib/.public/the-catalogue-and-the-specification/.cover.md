# The Catalogue and the Specification

- **author:** [Libby](../../../../.claude/library/..teamsmanship/..team/libby/libby-and-the-tended-garden/.cover.md)
- **coauthor:** [Arthur](../../../../.claude/library/..teamsmanship/..team/arthur/arthur-or-the-shape-of-everything/.cover.md), [Cathy](../../../../.claude/library/..teamsmanship/..team/cathy/cathy-and-the-reactive-canvas/.cover.md), [Adam](../../../../.claude/library/..teamsmanship/..team/adam/adam-between-the-wires/.cover.md)

---

***A research project, and the record of it.*** The binder — the compiler that turns a library of books into a published site — works, and working is no longer enough: a one-property change to how a page LOOKS costs a forty-second build to see, and the sheet it produces is 238 rules of which 39 must name five classes before they can say anything. **Doug, 2026-09-17: *"We have a prototype. It just died. Let's have the next version bring it back to life."*** This book is the research that decides what the next version is.

**It is written as a project rather than as an account**, which is unusual here and deliberate: the chapters carry the commission, the method, the questions and the searches *before* any result, so that a reader can judge whether the research was aimed at the right thing — and so that a later session can run it again against a changed world. The settled account that comes out of it belongs in a different book; ***this one is the trail.***

**THE ANCHOR, given as a constraint rather than a preference:** *"support for hot reload is obviously ESSENTIAL… restarting a server is death."* Every proposal here is judged against it first.

**AND THE SECOND ANCHOR, which draws the hardest line in the book:** *"if we need to read certain things by parsing and consuming the page itself rather than running something, we can validate the library in code too. But that's really really hard."* It is. What can be settled by parsing the emitted HTML and CSS — which rules match, which wins, whether a declaration is there at all — is finite work with no browser in it. What cannot be settled without laying the page out — a column that collapsed to 24 pixels, a row that wrapped, a mark that fell to the next line — is exactly the class of fault this library keeps shipping. ***Parse what can be parsed; run only what must be run*** is the rule the architecture is held to, and the residue is the subject.

6. [The Language and What It Compiles Into](06-the-language.md) — THE LANGUAGE AND WHAT IT COMPILES INTO, rewritten because the notation it first documented was retired the same day. THE ESSENCE, which is the thing to hold: authorship begins in a single act of self-representation and is extended only by delegation — one book comes into being that authors itself, the only claim in the library needing no authority behind it because nothing above it exists to grant one, and every further representation must be catalogued by an author AND authored by that author. Doug: 'starting with a self-delegation that only happens once' and 'it referentially colors the tree in an interesting way, including the tree that contains the authors.' There is no external registry of who may write — the permission is a REGION OF THE SAME STRUCTURE it governs. THE SEVEN FORMS: dollar-bracket only refers, double-bracket only annotates, and the SIDE the stars stand on is the direction of the edge relative to the writing they are in — left points out, right points in, and the stars count outward through widening relations, one author, two canonical catalogue, three catalogue. The third postfix is a PROPOSAL the fixture forced: a table must name a book without claiming its name, and only the canonical relations had a form to answer with. WHAT IT COMPILES INTO: every annotation is half of an edge and both spellings normalise to the same key, so one map keyed by the edge and holding every assertion that made it answers three faults at once — whole, a claim nothing corroborates, and a contradiction. Five layers each because a check needs it: assertions with provenance because a two-ended fault must be reported at BOTH ends; spots keyed by where they stand and never by name; NAMES AS A MULTIMAP DELIBERATELY, because an earlier writing keyed cards by title in a plain Map and six books silently became five; relations with different TYPES so a cycle check cannot run on the one where cycles are fine; and the COLOURING, one downward flood admitting a child only if its catalogue is an author and its author is that catalogue. Strings live at the boundary of the parse and nowhere after it. AND EVERY FAULT NAMED IN THE LIBRARY'S OWN WORDS — Doug: 'you have to map them to errors in the semantics of the actual framework, duplicate title, missing this, no catalogue for this' — fourteen of them, standing where a compiler puts its error code. Ends with the seven cases run against a built fixture, including the Peano case where two books catalogue each other topically and the library is well-formed, and the case that failed for the WRONG reason, which is the only thing that found a real bug. SINCE 2026-09-25 in .public's compiler, Subject collapses the author syntax: [[ X ]]* has left the language, an author edge is said by its By alone, each answer keeps the count of the link it answers, and who may author is one step — the one book by its own subject, and the books whose subject it is.
