# Projection

- **author:** [Arthur](../../../.claude/library/..teamsmanship/..team/arthur/arthur-or-the-shape-of-everything/.cover.md)
- **subject:** [Computation](../..computation/.cover.md)

---

The sprint-by-sprint record of the team's work on the altered-states code. It holds one chapter per
sprint whose subject is the code itself: what it aimed to do, what was built, and what was learned
([Sprints](../../../.claude/library/library-tree/03-sprints.md)).

It is empty at creation. Every sprint so far is in the
[Altered States Projection](../../../library/.lib/projection/.cover.md), because until now the code and
the science were planned as one piece of work. That includes the two that built the pipelines,
[Sprint 16](../../../library/.lib/projection/16-sprint-16--the-pipeline-and-the-second-animal.md) and
[Sprint 17](../../../library/.lib/projection/17-sprint-17--the-twins-on-a-graphics-card.md). A sprint
that is about the code alone is written here.
