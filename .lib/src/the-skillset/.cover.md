This project's own skills: the slash commands that belong to altered-states alone, because they drive its machines and reach its lab. They are written here, in the branch library, rather than in the identity's [Our Skillset](../../../.claude/library/our-skillset/.cover.md). The branch library travels with this project and never merges into the organisation, so no organisation merge can overwrite them, and their numbers cannot collide with the organisation's; the organisation's 34 is `catchup`, which is where `als-remote` once sat.

The same compiler builds them into `.claude/skills/` and refuses any name defined in two skillsets ([On Skills](../../../.claude/library/..environmentalism/04-on-skills.md#branch-local-skillsets)). Doug, 2026-10-05: *"Maybe even some sort of branch local skillset? ... I don't want them overwritten."*
