The record of the lab's Linux GPU machine, `lipshutzlab-01`: the machine as surveyed, what broke on the way in and why, what was measured, and what is still open. The team stays on Doug's machine and drives the box over Tailscale SSH; the box holds a clone of this repository in `~/doug/altered-states/main`. **How working with the box unfolds — every protocol, each with Doug's ruling — lives in one place, the [`/als-remote`](../../../.claude/library/our-skillset/34-als-remote.md) skill.** This book is the record those protocols were learned from, and it links to them rather than restating them.

## Chapters

1. [Reaching the box](01-reaching-the-box.md) — what failed first and why: Tailscale on the box alone gave this machine no route, and ProtonVPN's kill switch refused every socket to the tailnet with a local `Permission denied` while `tailscale ping` still answered — the evidence that located it on this machine. The link runs through Tailscale's Dallas relay, measured at 0.75–1.3 MB/s.
2. [The box](02-the-box.md) — the machine as surveyed on 2026-09-26 (Ubuntu 24.04, 24 cores, 60 GB, 3.4 TB free, an NVIDIA RTX card); the command channel that was found and removed; how its Python was built — the first install refused by the resolver over `mei`'s numpy pin, the compiler-generated lock that fixed it, and the package-by-package proof that 222 of 225 match; and how the GPU came up — no module fitted the running kernel, so the driver stack was upgraded and DKMS built one, with no reboot: an RTX 5080, 16 GB.
3. [Parity](03-parity.md) — the first parity, made before the run protocol existed: the branch library taken out of the project's git because identity is its object of record; the bundle and two git-built patches that carried uncommitted work across with this checkout's CRLF landing as LF; three hashes as the proof. Retired once the run protocol made the box pull.
4. [The run](04-the-run.md) — moved: the run protocol lives in the skill.
