The lab's Linux GPU machine, `lipshutzlab-01`, and how the team works on it without living on it. The team stays on Doug's machine and drives the box over Tailscale SSH; the box holds a clone of this repository in `~/doug/altered-states/main`, kept at exact parity with the working copy here — same HEAD, same index, same working tree — with nothing ever committed there. Git carries the code and the history; the ignored files (the scans, the caches) cross by tar over SSH, each path verified by sha256 on arrival; Python is rebuilt on the box rather than copied. Identity — `.claude/`, `CLAUDE.md`, every `.lib/` — never travels. The executable form is the [`/als-remote`](../../../.claude/library/our-skillset/34-als-remote.md) skill; this book holds the rulings it follows, what broke on the way in and why, and what is still open.

## Chapters

1. [Reaching the box](01-reaching-the-box.md) — what a connection needs at each end and what failed first: Tailscale on the box alone gave this machine no route, Tailscale SSH has to be switched on separately, the ACL's `check` mode would stall every non-interactive command, and ProtonVPN's kill switch refused every socket to the tailnet with a local `Permission denied` while `tailscale ping` still answered. The link runs through Tailscale's Dallas relay at a measured 0.75 MB/s.
2. [The box](02-the-box.md) — the machine as surveyed on 2026-09-26 (Ubuntu 24.04, 24 cores, 60 GB, 3.4 TB free, an NVIDIA RTX card), the folder layout and the deploy key already wired into the clone, where the sudo password lives and why there, and what is open: the NVIDIA driver has no module for the running kernel, and there is no Python 3.11 yet.
3. [Parity](03-parity.md) — Doug's rulings verbatim (nothing committed on the box, identity never travels, `main` the only branch until a job is dispatched), and how parity is made and proved: a bundle for the commits, two git-built patches for the index and working tree so CRLF lands as LF, three hashes equal on both ends; the branch library taken out of the project's git because identity is its object of record; the ignored files sent one verified path at a time.
