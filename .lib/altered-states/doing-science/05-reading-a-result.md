# Reading a result

- **author:** [Nancy](../../../.claude/library/..teamsmanship/..team/nancy/nancy-or-the-weight-of-evidence/.cover.md)

---

## Name the reference

*"Good for what?!?"* Never call a number good, bad, high or low without the standard it is measured against and where
that standard comes from. Another paper's score is not a standard our data owes anything to (*"you are the ringbearer
in a wedding not the doctor"*). On a figure the reference is drawn: the test images' median on the distance from the
blank, a test image against the others on the likeness.

## Call a null null

*"What do you think a result is? The pre- and post- metameric moments return the same result. So the result is
lost."* When two conditions read the same, say so in the first line and name the wall, especially when it is the data
or the instrument and not the method. On 2026-11-03 the likeness to the test images read 0.16 before DOI and 0.17
after: that went on the slide as it is.

## A measure must not restate another

Doug, 2026-11-03, on whether the activity at rest is more like the stimuli: *"Is it contrast invariant? (In some sense,
showing blank and showing natural should be independent I thinK? because otherwise you are just saying blank is less
like the stimuli than just about anything else because it is blank)."* A measure of how image-like the activity is must
not be a second reading of how far it sits from the blank. A correlation across cells ignores the level, so leaving the
blank does not raise it; it is not measured from the blank, so a faint image scores like the blank. Say what each
measure is blind to, and check that no statistic is another one restated.

## An uneven test is said to be uneven

*"focus first on suite2p ... Report both but equivlance and MEI and superior metamers was a reason to switch to suite2p
... caiman - it is not an even test because we are biased to suite2p in the metamer calculation."* When a method was
tuned on one arm, the other arm is reported with that said plainly, not presented as an independent replication.

## Paired arms, one footing

*"Consistency is what is conservative."* Before and after DOI match on every setting: cells, map, windows, twin. A
reason given for one arm's choice does not transfer to the pair.

## Read each recording on its own terms

Never argue from one recording's result that another cannot answer; run it and read it. Time within a recording is
not drug time (DOI lasts hours). No invented thresholds on a continuous curve. Across datasets, the same shape in both
is the evidence even when weak; an inconsistency means the comparison is not like for like.

## What the drug does is the result

*"the behaviour changed and the neural code changed — how do they relate."* A behavioural difference under DOI is part
of what DOI does: never regressed out, normalised away or controlled for. A readout that keeps its layout shows the
instrument held; it checks a dataset, never DOI.

## Don't project conservatism

*"in an effort to be conservative you are often wrong."* Conservative means not overclaiming. It never means doubting
a published effect, discarding data, or recommending the cautious option because it is cautious. He sets the level of
caution.
