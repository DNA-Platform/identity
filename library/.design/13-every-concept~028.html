What it is

The framework's Theme is bare: it stands on every book and provides itself, and nothing else. So the properties are this library's own. They are declared as fields on a class under the framework's Theme, and every rule beneath reads them through the theme's own provision, as a value templated into the string.

The component is one styled element, composed of parts. Each part is a method returning a fragment of rules for one thing on the page, so that a book changes one part and keeps the rest, and a reader of the file sees the look as a list of named pieces.

How it is used

Declare the fields your library reads, as many as it has. Compose the parts in the field that holds the style. Then register the theme on your book class, once, in the file that exports the class; every book of the library inherits it, and a book that wants another theme registers its own.

export class $ManualTheme extends $LibraryBookTheme {
    measure = '58ch';                              // one value changed
    protected override parts(): RuleSet[] {
        return [...super.parts(), this.index()];  // one part added
    }
}
$(Manual, Theme)(ManualTheme);                       // registered on the book

A rule names a class the framework puts on an element, never the element itself; it reaches by descendant, never by child; and every quantity in it is one of these fields, never a literal. A face that must win over the theme on one element names the kind with its class, as the chapter on the faces says.

Fields

fontstringThe family every book is set in.
inkcolorThe color of the words. Every rule that needs it reads this field, so a book that changes it keeps the look in another ink.
papercolorThe color of the page behind them.
accentcolorThe color of a reference to another place in the library.

Before it bites

A style is compiled once per class, so a value is read through the provider's props and never through a closure over the instance. A part must not take the name of a member the class already has; the typecheck names such a thing at once, and the page breaks somewhere else if it is not run. A font declared here reaches the live page only after a bind.
