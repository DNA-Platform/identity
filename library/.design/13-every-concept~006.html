The Theme

A place for the library's properties, and the one styled component that dresses the framework's marks with them.

What it is

The framework's Theme is bare, so the properties are this library's own. They are declared as fields and read by every rule beneath through the theme's own provision.

The component is composed of parts, each a method returning a fragment of rules, so that a book changes one part and keeps the rest.

Fields

fontstringThe family every book is set in.
inkcolorThe color of the words. Every rule that needs it reads this field, so a book that changes it keeps the look in another ink.
papercolorThe color of the page behind them.
linkcolorThe color of a reference to another place in the library.
