What IS the Transpiler?
The transpiler is a systematic translation process that converts SRT's linguistic notation into pure first-order logic (FOL). It's not just notation - it's a formal specification showing that every SRT expression has a precise FOL equivalent.
Critical Insight: SRT is built on top of FOL, not replacing it. The transpiler proves SRT is a semantic specification of FOL - a way of organizing and expressing FOL statements with semantic clarity.

The 8-Phase Transpilation Pipeline
The transpiler works in strict order - each phase depends on previous phases:
Phase 1: Basic FOL Extensions (Programming Style)
SRT replaces FOL's mathematical symbols with typeable equivalents:
!P         := ¬P          // NOT
P & Q      := P ∧ Q       // AND  
P || Q     := P ∨ Q       // OR
P =|> Q    := P → Q       // IMPLIES
P <iff> Q  := P ↔ Q       // IFF
Why? These are synonyms - both forms are valid. You can type & instead of ∧.
Quantifiers:
E[x]: P(x)    := ∃x: P(x)        // "there exists"
A[x]: P(x)    := ∀x: P(x)        // "for all"
Distinguished quantification:
E[x,y]: P(x,y)  := ∃x∃y: x != y & P(x,y)    // x,y must be distinct
E{x,y}: P(x,y)  := ∃x∃y: P(x,y)             // x,y may be equal
This is not just notation - it's expressing a semantic distinction about whether variables can collapse.

Phase 2: The Primitive Relation R(x,y,t)
SRT introduces one new relation to FOL's signature:
R(x,y,t) - a ternary relation meaning "x refers to y through relationship type t"
The linguistic form:
x =t> y    := R(x,y,t)
This is the ONLY primitive addition to FOL. Everything else is defined from this.
Compound forms:
x !=t> y           := ¬R(x,y,t)
x =t> y =s> z      := R(x,y,t) ∧ R(y,z,s)      // chain
x <s=t> y          := R(x,y,t) ∧ R(y,x,s)      // bidirectional

Phase 3: Equality Integration
SRT internalizes FOL's equality as a referent in the domain:
E[eq]: A[x,y]: x = y <iff> x =eq> y
This says: there exists a special referent eq such that FOL equality (x = y) is equivalent to R(x,y,eq).
Now we can use:
x == y    := x =eq> y    := R(x,y,eq)
x != y    := ¬(x =eq> y)
Why internalize equality? So equality becomes a semantic object we can reason about, not just a logical operator.

Phase 4: Base Relationship Type and Inheritance
SRT establishes r as the universal relationship type:
E[r]: A[x,y,t]: R(x,y,t) =|> R(x,y,r)
