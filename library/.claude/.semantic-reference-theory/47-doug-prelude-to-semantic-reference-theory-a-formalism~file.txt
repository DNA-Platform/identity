My theory of consciousness is based on Godelian self-reference. It started as an extension of first order logic where one can use a canonical metalanguage (like Godel created) to produce semantic assertions about the theory. Do you want to be sure you are doing logic? Reify your belief in logic by expressing belief in consistency with the provability predicate. Require a construction protocol for things like proof by contradiction or the sort of hypothetical implication proof where you assume something random, prove something else and conclude the assumption implies the conclusion. Where did those things come from? Well if construction is part of the process, when you construct with the metalanguage, you might bump into something that breaks a semantic assertion - like an assertion in programming - which is often compiled out for release! Or not. But it's not in the type system. Then, when one's semantic assertions (which cannot be axioms because the metalanguage depends on the axioms so the formalism would have to change to accomodate them) are violated, semantic reflection is the version of proof that kicks in to conclude that there's a problem with the semantic assertions. And if one can conclude that an action can be taken to preserve or restore consistency while also preserving the semantics of the thing you are doing, you can "transduce" new symbolic structures like axioms.

Why is a Godel sentence true? Because it violates the semantic assertions of logic that we make in the metalanguage. Sure, we can't prove consistency, but if transducing not G is like declaring yourself to be inconsistent in the metalanguage, then you would do well not to transduce not G. But why transduce G?
