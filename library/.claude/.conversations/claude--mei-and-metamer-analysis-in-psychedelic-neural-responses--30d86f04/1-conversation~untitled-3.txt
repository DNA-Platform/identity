## Sparse Coding and Natural Images

Olshausen and Field published seminal work showing the emergence of simple-cell receptive field properties by learning a sparse code for natural images (Nature 1996). They followed this with research on sparse coding with an overcomplete basis set, proposing it as a strategy employed by V1.

## Overcomplete Dictionary and Linear Combinations

When the code is overcomplete—i.e., when the number of code elements is greater than the effective dimensionality of the input space, natural images can be represented as linear combinations of basis functions. Because the basis functions are non-orthogonal and not linearly independent of each other, sparsifying the code will recruit only those basis functions necessary for representation.

## Receptive Fields and V1 Properties

The spatial receptive fields of simple cells in mammalian striate cortex are localized, oriented, and bandpass, and these receptive field properties may be accounted for in terms of a strategy for producing a sparse distribution of output activity in response to natural images. When sparse coding algorithms are applied to natural images, the learned bases resemble the receptive fields of neurons in the visual cortex.

This foundational work established the connection between sparse coding principles and the neural architecture of visual processing in the brain.
