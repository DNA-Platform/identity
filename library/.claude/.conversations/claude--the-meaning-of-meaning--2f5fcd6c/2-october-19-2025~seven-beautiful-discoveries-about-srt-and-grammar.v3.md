## **2. The Distinction Between (x,x) and (x)**

### **They Are Not The Same!**

**`(x,x)` — Self-relationship**:
```
(x,x) == x  // Token of subjectivity
```

When an entity's self-relationship equals itself, it possesses subjectivity.

**For subjects**:
```
x => y =|> (x,x) -> (x,y)
```

"The way a subject relates to itself most specifically is in the way it relates to objects."

**`(x)` — Canonical symbol**:
```
(x) =(x)> x
```

The symbol that represents x.

**Key insight**: 
- `(x,x) == x` means the entity IS subjective
- `(x)` means the entity HAS a symbol
- They're related but distinct concepts!

## **3. The Complete Notation System**

SRT introduces four perfectly symmetric operations:

### **The Four Operations**

**Symbolize upward**: `(x)` — Canonical symbol of x
```
(man) — the word "man"
```

**Dereference downward**: `[x]` — Access referent/representative
```
[(man)] == man
```

**For symbols**: Dereferencing returns the referent
```
[(x)] == x
```

**For representations**: `[x]` represents the canonical representatives
```
[x] =[x]> y  when  (x,y) == x
```

When unique: `[x] == y` (the canonical)  
When not unique: `[x]` represents "a member" (hypothetical particular)

**Example**: If `x` represents "man":
- `[x]` is "a man"  
- Points to a particular one in absence of there being a particular one
- The **idea of one** when there isn't a unique one

**Property indexing**: `p[x]` — Property bound to x
```
tall[man] — tallness of this man
p[x] := ((x,x), p)
```

**Starting form**: `p[x] = ((x,x), p)`

**The relationship**:
```
(x,x) =((x,x), p)> ((x,x), p)
((x,x), ((x,x), p)) == ((x,x), p)
```

**Collapsed (normal case)**:
```
(x, (x,p)) == (x,p)
```

**This is representativity!** The relationship expresses how x represents property p.

**Function application**: `x(y)` — When (x,y) == x
```
When x is most specific relationship to y
```

### **The Three Levels of Reference**

```
(x) =sym> x =sym> [x]
```

Where:
- **(x)** — symbolic form in language (the word)
- **x** — semantic/conceptual referent (the meaning)
- **[x]** — literal/physical process (the reality)

**Example with "see"**:
```
(see) =sym> see =sym> [see]
```
- **(see)** — the word "see"
- **see** — the concept of visual perception  
- **[see]** — phototransduction (literal physical process)

**Language resolves into conceptual reference first**, only into literal reference when context demands.

## **4. "The Sky Is Blue" — Why It's Perfect**

```
(the sky) =blue> the sky
```

### **Why This Example Reveals Everything**

**Blue is subjective** — a perceptual category, not a literal fact:

> "The EM spectrum is a line without breaks, but the 'is' forces the symbol to express the subjective character."

Nothing "real" about color categories—they're **subjective cuts on a continuum**.

### **The Structure**

Still has `subject =relationship> object` form, but:
- **blue** is a characteristic that represents a property
- **The subject is a reference for the object** (symbol for literal)
- The copula "is" forces symbolic expression of subjective character

**Dereferencing**:
```
[(the sky) =blue> the sky]
means: [the sky] =blue> [the sky]
```

Where `[the sky]` is "a pointer to the real sky that's blue, whichever sky that is."

## **5. The Subjective-Objective Distinction**

### **Characteristics vs Properties**

**Characteristic** (subjective):
```
x =characteristic> x
```
The entity's self-expression—how it relates to itself.

**Property** (objective):
```
(x) =property> x
```
An observer's representation of the entity bearing that property.

### **Character vs Type**

**Character** (subjective):
```
man — the character, the nature of being a man
```

**Type** (objective):
```
Man — the type/class in formal system
```

### **Particular vs Instance**

**Particular** (subjective):
```
(the man) — this specific man, whoever he is
```

**Instance** (objective):
```
man₁ — a formal instance of type Man
```

### **The Ontological Hierarchy**

```
characteristic → character → particular (subjective)
     ↓              ↓            ↓
property      →  type    →  instance  (objective)
```

**The key**: When characteristics are bound to literals in a reference frame, they become properties. The character of an object becomes its type.

**Critical distinction**: Objects don't sustain self-relations. Their "having" of properties exists only in representation by subjects.

## **6. Subjectivity Through Inheritance**

### **The Token of Subjectivity**

```
(x,x) == x
```

### **Property Inheritance**

For subjects:
```
x =p> x & (x,x) == x =|> x -> p
```

**A subjective referent inherits from its own properties.**

### **Example: "The man throws the ball"**

```
(the man) =throw> (the ball)
```

**Subjectivity analysis**:
```
(man, man) -> (man, ball)
(man, ball) -> throw
Therefore: (man, man) -> throw
```

The man's self-relationship inherits from how he relates to the ball.

**But**:
```
(ball, ball) does not inherit from (man, ball)
```

The ball possesses no subjectivity—doesn't represent its relationship.

### **The Principle**

**For subjects**: Their self-relationship inherits from their external relationships.

**For objects**: No self-relationship; properties assigned only through representation.
