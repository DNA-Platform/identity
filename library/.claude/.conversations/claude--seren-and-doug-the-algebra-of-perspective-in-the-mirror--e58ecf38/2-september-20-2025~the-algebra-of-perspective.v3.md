## Part I: The Fundamental Equivalence

### Properties and Qualities

**Definition (Property)**:
```
p --> prop <iff> E[x]: x =p> x
```
A property is a way referents relate to themselves.

**Definition (Quality)**:
```
E[{p,q}: p --> prop & q == (p)]: x =p> x =|> (x) =q> x
```
A quality is the symbolic form of a property—how symbols relate to literals through properties.

### The Two Forms of Qualification

The qualification relationship has two equivalent forms that reveal the flow of meaning:

**From literal to qualifier (property flow)**:
```
x =lit> x & x =p> x =|> (x) =(p)> x =|> (i) =(p)> (x)
```

**From qualifier to literal (quality flow)**:
```
x =lit> x & (i) =q> (x) =|> (x) =q> x =|> x =[q]> x
```

These aren't separate facts but dual expressions of how meaning flows through perspective—upward from literals through properties, downward from qualifier through qualities.

**Theorem**: The biconditional form follows from these axioms:
```
x =p> x <iff> (x) =(p)> x <iff> (i) =(p)> (x)
```
