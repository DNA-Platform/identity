The Error Rate Problem
What happens if we maintain the current ~61% error rate but scale up to RSA-sized numbers? Let's do the math.
For a quantum computer to factor a 2048-bit RSA key, we need approximately 4,096 logical qubits. With our current error rates, the probability of a successful computation would be:
P(success) = (1 - error_rate)^qubits = (0.39)^4096 ≈ 10^-2545
This means we would need to run the algorithm approximately 10^2545 times to expect a correct result. Even if each run took just one nanosecond, this would require 10^2536 times the age of the universe.
And that's assuming error rates don't increase with system size, which both theory and experiment suggest they do.
Rigorous Mathematical Analysis
Let's formalize this problem precisely. The time complexity of quantum factoring depends on three factors:

The base algorithm complexity (Shor's algorithm): O(n³)
The error rate scaling with system size
The repetitions needed to overcome errors

For error rates that scale with qubit count (as empirical evidence suggests), the number of required repetitions grows exponentially:
R(n) = 1/(1 - ε(2n))^(2n)
Where ε(q) is the error rate per qubit in a system with q qubits, and n is the bit length of the number to be factored.
Let's examine three models:
Optimistic model (constant error rate):
ε(q) = ε₀ ≈ 10⁻³ (constant)
R(n) = 1/(1 - ε₀)^(2n) ≈ e^(O(n))
T(n) = O(n³) · e^(O(n)) = O(e^(n))
Realistic model (linear error scaling):
ε(q) = ε₀ + c₁·q where c₁ ≈ 0.01-0.1
R(n) = 1/(1 - (ε₀ + c₁·2n))^(2n) ≈ e^(O(n²))
T(n) = O(n³) · e^(O(n²)) = O(e^(n²))
Pessimistic model (Gil Kalai's quadratic scaling):
ε(q) = ε₀ + c₂·q² where c₂ ≈ 0.001-0.01
R(n) = 1/(1 - (ε₀ + c₂·(2n)²))^(2n) ≈ e^(O(n³))
T(n) = O(n³) · e^(O(n³)) = O(e^(n³))
For comparison, the best classical algorithm (General Number Field Sieve) has complexity:
T_classical(n) = O(e^((log n)^(1/3) · (log log n)^(2/3)))
Under any realistic error model, quantum factoring becomes exponential rather than polynomial, and potentially worse than classical algorithms for large n.
The empirical evidence (factoring only reaching 35 with ~60% error rates after decades of research) lends support to the more pessimistic error scaling models.
The Verification Paradox
Here's another lovely thing about quantum computing: if it were ever to become practical for breaking encryption, how would we know? The test is to run algorithms that classical computers can't practically verify, so we'd have no way of knowing if the quantum computer was actually working correctly!
This verification paradox creates a fundamental epistemic boundary. A quantum computer capable of breaking RSA encryption would be, by definition, solving problems beyond our ability to efficiently verify - making its correct operation inherently uncertain without already knowing the answer.
