The BSN uses the 'elfproef' (11-proof), a check digit algorithm.

CONSTRAINTS:
  1. Exactly 9 digits: N1 N2 N3 N4 N5 N6 N7 N8 N9
  2. At most one leading zero (cannot start with '00')
  3. Weighted sum using weights [9, 8, 7, 6, 5, 4, 3, 2, -1]:
     S = 9×N1 + 8×N2 + 7×N3 + 6×N4 + 5×N5 + 4×N6 + 3×N7 + 2×N8 + (-1)×N9
  4. S must be divisible by 11 (S mod 11 = 0)
  5. S must be > 0

NOTE: The last weight is -1 (not +1). This is what distinguishes the BSN
variant from the standard elfproef used for old Dutch bank account numbers.
