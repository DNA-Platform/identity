MathJS - The Kitchen Sink
MathJS is huge - about 700KB minified, 170KB gzipped. It includes:

Complex numbers (which you need!)
Matrices (all operations)
Statistics
Probability
Expression parsing (math.evaluate('2 + 3 * 4'))
Units (math.evaluate('5 inch to cm'))
BigNumbers for arbitrary precision
And much more...
The good news: It's modular! You can import just what you need:

typescript
// Instead of importing everything
import * as math from 'mathjs'

// Import only what you need
import { complex, add, multiply, sqrt } from 'mathjs'
GL-Matrix - The Speed Demon
GL-Matrix is tiny - about 55KB minified, 15KB gzipped. It gives you:

2D vectors (vec2)
3D vectors (vec3)
4D vectors (vec4)
2x2, 3x3, 4x4 matrices
Quaternions
Dual quaternions
It's specifically optimized for graphics operations and uses typed arrays for speed.

Can We Have Both?
Absolutely! And with Vite's tree-shaking, you only bundle what you actually use. Here's a hybrid approach:

typescript
// Use gl-matrix for basic vector operations (FAST)
import { vec2 } from 'gl-matrix'

// Use mathjs for complex numbers and special functions
import { complex, add as complexAdd } from 'mathjs'

// Your Vector class wraps both!
class Vector {
  private glVec?: Float32Array  // For real vectors
  private complexData?: any      // For complex vectors
  
  // Use gl-matrix for simple operations
  plus(other: Vector): Vector {
    if (!this.isComplex()) {
      const result = vec2.create()
      vec2.add(result, this.glVec, other.glVec)
      return new Vector(result)
    } else {
      // Use mathjs for complex operations
      return this.complexAdd(other)
    }
  }
}
How Vite Handles This
Vite + tree-shaking means:

Development: Libraries stay separate, fast HMR
Production Build:
Only used functions are included
Dead code eliminated
Everything in one HTML file (your single-file plugin)
For example:

typescript
// Only these specific functions end up in your bundle
