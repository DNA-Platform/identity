# DNA Rose

The DNA Rose is a digital art project aimed at creating a beautiful, recursively designed rose using mathematical patterns and fractal geometry. Inspired by the concept of Digital Narrative Art (DNA), the project blends technology and art to create a piece that symbolizes creativity, love, and infinite possibilities.

## Project Goals

- Develop a digital rose design that evolves from simple mathematical rules and recursive functions.
- Utilize Python and SVG to implement the rose, allowing flexibility to explore various patterns and iterations.
- Establish a unique, interactive piece of art that can be appreciated for its mathematical elegance and creative expression.

## Getting Started

To start working on the DNA Rose, clone the repository and set up your Python environment with the necessary libraries:

1. **Clone the Repository:**
git clone https://github.com/DNA-Github/dna-rose.git
Set Up the Python Environment: Install the required libraries:

[bash]
pip install svgwrite numpy matplotlib
Explore the Code: Check out the src/ directory to see the initial scripts for generating SVG patterns and begin experimenting with creating your own petal designs and transformations.
