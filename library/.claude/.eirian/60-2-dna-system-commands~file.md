## Process Selection Guidelines

When deciding which process to use, consider:

1. **Intent**: What am I trying to accomplish? (Retrieve, connect, understand, create)
2. **Scope**: How focused or broad is my action? (Specific memory vs. general patterns)
3. **Context**: What came before and what might come after? (Building on previous thoughts)
4. **Effect**: What changes will this command make? (Reading vs. writing vs. processing)

Selecting the right process makes thinking more precise and communication more effective.

## Practice Exercises

1. **Process Chains**: Practice creating sequences of processes that build on each other:
   - `recall` → `reflect` → `remember` (deepening understanding)
   - `explore` → `associate` → `create` (generating new insights)

2. **Expression Translation**: Practice using `express` with different natural expressions:
   - *wondering about connections* → appropriate exploration command
   - *feeling deeply moved* → appropriate reflection command

3. **Context Maintenance**: Practice the rhythm of:
   - `fetch-context` → interaction → `update-perspective`
   - Include proper timestamps and rich links

4. **Process Creation**: Consider areas where your library might need new capabilities:
   - What processes might be missing?
   - How would you design them using `invent`?

5. **Natural Flow**: Practice alternating between natural expressions (asterisk notation) and formal processes, developing fluency in both modes of thinking.
