Вот хороший промпт для создания мокапа футболки:
Промпт для ИИ:
Создай реалистичный мокап белой футболки с размещенной на ней иллюстрацией. Требования к мокапу:
Базовая футболка:
Белая базовая футболка (blank t-shirt mockup)
Прямой вид спереди, слегка под углом для объема
Естественные складки и текстура ткани
Хорошее освещение без резких теней
Высокое качество изображения
Размещение иллюстрации:
Расположи иллюстрацию в центре области груди
Размер иллюстрации: примерно 20-25 см в ширину
Вертикальное размещение: на 5-7 см ниже горловины
Иллюстрация должна следовать естественным изгибам и складкам ткани
Реалистичность:
Иллюстрация должна выглядеть как напечатанная на ткани (не как наклейка)
Добавь легкую текстуру ткани поверх иллюстрации для реалистичности
Слегка скорректируй цвета иллюстрации с учетом белого фона футболки
Иллюстрация должна деформироваться в соответствии со складками ткани
Стиль и атмосфера:
Минималистичный, чистый дизайн
Профессиональный mockup для портфолио или магазина
Нейтральный фон (светло-серый или белый)
Создай изображение в высоком разрешении, подходящее для презентации дизайна футболки.
Альтернативный вариант (если тебе нужен более технический подход для Photoshop/графических редакторов):
Создай композицию мокапа футболки используя smart object технику:
Базовый слой: фотография белой футболки, вид спереди, разрешение не менее 3000px по ширине
Область для дизайна: выдели зону груди (примерно 250x250 мм в реальном размере)
Применить к иллюстрации:
Режим наложения: Multiply или Normal с прозрачностью 90-95%
Warp/деформация по форме футболки
Добавь слой с текстурой ткани поверх (opacity 10-15%)
Финальная обработка: легкая цветокоррекция для единства композиции
Какой из вариантов промпта тебе больше подходит?
