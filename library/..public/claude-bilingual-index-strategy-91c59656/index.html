No, Telegram desktop doesn't have a setting to always display the date on every message. By default it shows:
Date separators between messages from different days
Timestamps when you hover over individual messages
There's no built-in option to change this behavior. It's been a feature request from users for years, but Telegram hasn't implemented it.
