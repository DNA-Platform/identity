Claude
06:18 UTC, 23 February 2026
Alias domains in Google Workspace don't create separate accounts — they automatically create matching email addresses for every existing user. So if you have doug@dna.love, adding atlas.love as an alias domain automatically gives you doug@atlas.love as well. Mail sent to either address lands in the same inbox.
The key thing: you cannot log in with an alias domain address. You always sign in with your primary domain credentials (doug@dna.love). The alias address only works for receiving (and sending) email — it's not a separate identity or account.
To send from your atlas.love address, go to Gmail settings and you should be able to select it as a "Send as" address since Gmail is activated on both domains.
If what you actually wanted was a completely independent second account/login, you'd need to add atlas.love as a secondary domain (not an alias domain) and then create a separate user on that domain. That would count as an additional user seat on your Workspace plan. You'd remove the alias domain first, then re-add it choosing "secondary domain" instead.
