How much does it cost to have a house appraised
Claude
16:56 UTC, 26 November 2024
A typical home appraisal in the US costs between $300 and $600 for most residential properties, though the exact cost varies based on several factors:
Key factors affecting appraisal cost:
Size of the home (larger homes generally cost more to appraise)
Location (urban areas tend to be more expensive than rural)
Property type (single-family homes are usually less expensive than multi-family)
Property complexity (unique features or extensive land can increase cost)
Market conditions (busy housing markets may have higher fees)
Special circumstances that can increase costs:
Rush orders (expedited appraisals often cost 20-50% more)
FHA appraisals (typically $50-100 more than conventional)
Properties in remote locations (travel fees may apply)
Complex or unusual properties
Most lenders require the buyer to pay for the appraisal upfront, though in some cases this cost can be rolled into closing costs. For conventional home purchases, the appraisal fee is typically paid when the appraisal is ordered, not at closing.

To find the total growth over 15 years with 4% annual growth:
The formula is: Final = Initial × (1 + r)^t where r = 0.04 (4%) and t = 15 years
Starting with $1 (or 100%): Final = 1 × (1 + 0.04)^15 = 1 × (1.04)^15

Is it possible to use python to fill in a google sheet column? Or any other language? I know google has custom logic you can add

17:32 UTC, 26 November 2024
Yes, there are several ways to interact with and update Google Sheets programmatically:
Using Python with Google Sheets API:
python
from google.oauth2.credentials import Credentials
from googleapiclient.discovery import build
from google.oauth2 import service_account

SCOPES = ['https://www.googleapis.com/auth/spreadsheets']

def update_sheet(spreadsheet_id, range_name, values):
    creds = service_account.Credentials.from_service_account_file(
        'credentials.json', scopes=SCOPES)
    
    service = build('sheets', 'v4', credentials=creds)
    body = {'values': values}
    
    service.spreadsheets().values().update(
        spreadsheetId=spreadsheet_id,
        range=range_name,
        valueInputOption='USER_ENTERED',
        body=body).execute()
Google Apps Script (JavaScript):
javascript
function updateColumn() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var range = sheet.getRange("A2:A10"); // Adjust range as needed
  
  // Example: Fill with numbers
  var values = [];
  for(var i = 1; i <= range.getNumRows(); i++) {
    values.push([i]); // Each inner array represents a row
  }
  
  range.setValues(values);
}

function processData() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var data = sheet.getDataRange().getValues();
  
  // Process each row
  data.forEach(function(row, index) {
    if (index === 0) return; // Skip header
    
    // Example calculations
    var quantity = row[1];
    var price = row[2];
    var total = quantity * price;
    
    // Update total column
    sheet.getRange(index + 1, 4).setValue(total);
  });
}

Can I keep some posts private and make others public on reddit?
Claude
18:31 UTC, 26 November 2024
No, you cannot set individual posts as private on Reddit. Reddit offers these main visibility options for posts:
Public - Posted to a public subreddit, visible to everyone
Hidden - Only hides posts from YOUR view (others can still see them)
Deleted - Removes the post entirely but cannot be recovered
Posting to your profile - Still public but appears on your profile
Posting in a private/restricted subreddit - Only approved members can see
If you want to keep some content private, you could:
Use a separate Reddit account for private/personal posts
Save posts as drafts in a notes app instead of posting
Post sensitive content only in private subreddits where you trust the members
Use the "Save" feature to bookmark posts privately for yourself
Note that even deleted posts may be cached or archived elsewhere, so it's best to assume anything posted to Reddit could become permanently public.
