The original is Nikolai's 132-page technical overview, Telegram Open Network, dated December 3, 2017. Direct PDFs:
https://www.docdroid.net/JtdY7Jg/ton-pdf
https://ton-blockchain.github.io/docs/ton.pdf (the canonical mirror referenced by nLab and Wikipedia's Wayback archive)
For the rest of the original Durov-authored stack, same authorship, not the foundation rewrites:
Telegram Open Network Blockchain (Sep 2018, 121 pp.) — https://ton.org/tblkch.pdf
Telegram Open Network Virtual Machine (Sep 2018, 148 pp.) — https://ton.org/tvm.pdf
Catchain Consensus: An Outline — https://ton.org/catchain.pdf
The nLab page is the cleanest single index to all four: http://nlab-pages.s3.us-east-2.amazonaws.com/nlab/show/Telegram+Open+Network
