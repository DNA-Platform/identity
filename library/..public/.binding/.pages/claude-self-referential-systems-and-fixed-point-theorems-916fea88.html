There's a single master result underneath everything you're asking about, and the most useful thing I can do is name it first and then show how each concrete system is a special case — including the cases where the self-reference fails, which turn out to be governed by the same machinery.
The master key: diagonalization has two faces
Lawvere's fixed-point theorem (1969) is the right altitude to start from. In a cartesian closed category, if there exists a point-surjective morphism A → B^A — a single object A rich enough to "name" every map A → B — then every endomorphism B → B has a fixed point. Yanofsky's A Universal Approach to Self-Referential Paradoxes, Incompleteness and Fixed Points (2003) is the readable unification: Cantor, Russell, Gödel, Tarski, Turing's halting problem, and Kleene's recursion theorem are all the same diagonal argument, differing only in whether the relevant endomap happens to have a fixed point.
That "only" is the whole story. The point-surjectivity hypothesis — an object that encodes all the maps into itself — is exactly the existence of a universal machine, a programmable interpreter. Where you have that closure, diagonalization gives you fixed points constructively (you can build self-referential things). Where you lack it, or where the endomap you care about is fixed-point-free (like Boolean negation, which is why there's no surjection onto the powerset), the same diagonal gives you a limitative result (you cannot build the thing). So self-reference is simultaneously a construction technique and an impossibility theorem, and which one you get is a precise structural question, not a vibe.
The positive branch: what self-reference lets you build
Kleene's second recursion theorem is the computability-theoretic instance of Lawvere on the side where the fixed point exists. For any total computable f there is an index e with φe = φ{f(e)}: any computable transformation of programs has a program that behaves identically to its own transform. The operational reading is the one you want — a program can be given access to its own source code without infinite regress. Quines are the trivial case (f = "print"). It's also exactly what makes the untyped λ-calculus's Y combinator legitimate: recursion-via-self-application and the recursion theorem are the same phenomenon, which is why first-class self-application buys you Turing completeness.
Self-hosting compilers are this fixed point made industrial. A compiler for L written in L is grounded not metacircularly but by bootstrapping: an initial binary (hand-written, or compiled from another language) compiles the source, and you seek a stable point where compiling the source with the resulting binary reproduces that binary. The deepest illustration is Thompson's Reflections on Trusting Trust (1984): a compiler can be rigged so that compiling its own clean source reproduces a backdoor that appears nowhere in the source. That is a literal recursion-theorem fixed point with a security payload — the program reproduces its own behavior, injection included. Wheeler's diverse double-compilation is the countermeasure, and it works precisely by breaking the assumption that the fixed point is unique. CakeML (Myreen and collaborators) is the constructive triumph here: a compiler verified down to machine code, where the bootstrapping itself is formalized inside the proof.
Self-describing specifications are the fixed point at the level of documents, and they're the cleanest match to your "specs that specify how specs work." Define an operator conformsTo(D, S) — document D satisfies schema S. A meta-schema is a fixed point M with conformsTo(M, M): a document that validates itself. JSON Schema's meta-schema does exactly this; XML Schema has a schema-for-schemas; RDF Schema is expressed in RDF; and the OMG's MOF is reflexively defined — the four-layer M0–M3 tower terminates not by adding an M4 but by having M3 be an instance of itself. The regress stops at a fixed point, which is the only honest way to stop it.
Metacircular evaluators and reflective towers are worth distinguishing carefully, because they're the place people fool themselves. A Lisp eval/apply written in Lisp (SICP) is metacircular: it defines application using application, so it presupposes what it defines and grounds nothing on its own. It becomes meaningful only relative to a non-metacircular base — an actual implementation, or the recursion theorem to make the self-application well-defined. Smith's 3-Lisp and the Friedman–Wand reflective tower formalize the infinite interpreter-running-interpreter stack, and that tower is itself defined as a fixed point.
Denotational semantics closes the loop at the level of meaning, and this is the part most directly about "an execution environment the system specifies for itself." A language with first-class functions, or one that can reflect on its own programs, needs a semantic domain D isomorphic to its own function space, D ≅ [D → D].
