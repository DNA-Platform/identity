Core Framework Concepts
Chemistry ($Chemistry) is a revolutionary React framework that brings true object-oriented programming to React while keeping TSX syntax. The key innovation is treating React components as actual objects with real inheritance, not just functions.
Key Design Principles:
Convention over Configuration - Like Ruby on Rails, Chemistry uses naming conventions to eliminate boilerplate:
$ prefix = reactive prop from parent
_ prefix = non-reactive/private property
Class name as method = constructor for children
view() = render method
Children as Constructor Arguments - The breakthrough pattern where JSX children become typed constructor parameters: ``typescript <Book> <Title /> <Chapter /> <Chapter /> </Book> // Maps to: $Book(title: $Title, ...chapters: $Chapter[])``
True Polymorphism - Subclasses can override parent behavior, something React makes nearly impossible: ``typescript class $FancyBook extends $Book { // Can override how chapters are handled }``
Technical Implementation:
$Chemical - Base class for all components with reactive properties
$Bond - Manages property reactivity and state tracking
$Formula - Handles the reactive state system
Prototypal Magic - Components start as templates, become instances when bound
Symbolization - Converts object graphs to strings for deep equality without immutability
Registry System - Tracks component instances across React's re-renders
Structural Components:
The $ component (implemented as $Collection) acts as an array grouping mechanism:

  <Chapter />
</$>
Progressive Adoption:
Chemistry components work as regular React components (no $ visible)
Can "chemistrify" existing React components
Mix Chemistry and React components freely
Drop down to raw React for performance-critical sections

Polymorphic components
React interop

Chemistry eliminates React's complexity:
No useState, useContext, useCallback, etc.

// Add a global symbolizing flag
let $symbolizing = false;

function symbolize(value: any): string {
    // If already symbolizing, just proceed (handles recursive calls)
    if ($symbolizing) {
        return stringify(value, symbolizeReplacer);
    }
    
    // Set flag to disable reactivity globally
    $symbolizing = true;
    
    try {
        return stringify(value, symbolizeReplacer);
    } finally {
        // Always restore flag
        $symbolizing = false;
    }
}

function symbolizeReplacer(this: any, key: string, val: any): any {
    if (key === '') return val;
    if (val instanceof $Chemical) return val[$cid];
    if (this instanceof $Chemical) return this[$cid];
    if (typeof val === 'function') return undefined;
    if (val?.constructor?.name === 'Proxy') return '[Proxy]';
    return val;

private bondGet() {

The state tracking problem is that:
The async function is running
It awaits a Promise
Promise resolves
Async function immediately continues, setting properties
THEN the .then() handler runs
By the time any .then() handler runs, all the property assignments from the async function have already happened. There's no JavaScript mechanism to run code "after Promise resolves but before the async function continues."
