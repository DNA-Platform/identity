beforeEach() runs for all tests within its scope and all nested describe blocks.
So if you put it where you have it:
typescript
describe('$Reflection', () => {
    describe('$ObjectiveRep', () => {
        describe('$type function', () => {
            beforeEach(() => {
                $lib.$reset();
            });
            // Only runs for tests inside '$type function'
It will only run for it() blocks inside '$type function'.
If you want it to run for all tests in the file, move it to the top:
typescript
describe('$Reflection', () => {
    beforeEach(() => {
        $lib.$reset();  // ✅ Runs before EVERY test in $Reflection
    });
    
    describe('$ObjectiveRep', () => {
        describe('$type function', () => {
            // beforeEach from parent runs here too
If you want it for all $ObjectiveRep tests but not parseFunctionInfo tests:
typescript
describe('$Reflection', () => {
    describe('$ObjectiveRep', () => {
        beforeEach(() => {
            $lib.$reset();  // ✅ Runs for all $ObjectiveRep tests
        });
        
        describe('$type function', () => { ... }
        describe('other tests', () => { ... }
    });
    
    describe('parseFunctionInfo', () => {
        // beforeEach doesn't run here
    });
Rule of thumb: Put beforeEach() at the highest level where you need it to apply.
