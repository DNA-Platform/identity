Ten Deep Questions (And Answers)
Q1: How does Chemistry handle React's reconciliation while maintaining stable object instances?
A: Chemistry uses a cid (chemical ID) stored in React's useState. When React re-renders, it checks if cid === -1. If not, it retrieves the existing Chemical from chemicalRegistry. This ensures the same object instance persists across renders while React handles its own reconciliation.
Q2: How does the symbolize() function prevent memory leaks while tracking complex state?
A: symbolize() uses fast-safe-stringify to convert the entire state to a string representation, replacing Chemical instances with theircid. This breaks reference chains (preventing leaks) while allowing deep equality comparisons. The trade-off is performance overhead for complex objects.
Q3: How do structural components like $ get removed from the DOM while preserving their children?
A: The $Array component has a static extract() method that returns { dom: ReactNode[], data: any }. Chemistry's __processChildren detects structural components, calls extract(), splices the dom children into the parent's children array, and passes data to the constructor. The $ component never actually renders.
Q4: What happens when a parent re-renders with the same children - how are instances reused?
A: Chemistry tracks children by position/type. In the constructor (called every render), it could implement an equals() method to determine if a new child is "the same" as an existing one. If equivalent, it updates properties on the existing instance rather than creating a new one.
Q5: How does the getter-based state tracking avoid pollution from non-view property access?
A: By convention: underscore-prefixed properties (_data) don't trigger state tracking. Methods can access these without pollution. Additionally, the @inert() decorator explicitly marks properties as non-reactive. Developers must design their Chemicals with this in mind.
Q6: How does Component.bind() create a permanently bound instance-component pair?
A: bind() creates a new $ComponentFunction with a specific Chemical instance. This instance is stored in closure and always used instead of creating a new one from the template. The returned Component is forever tied to that specific instance.
Q7: How are props made optional when using bound components?
A: Since bound components have direct access to their Chemical instance, you can set properties directly on the instance before rendering. The Component's props type becomes Partial<P> - all props optional because they can be set imperatively.
Q8: How does Chemistry handle async views with the Promise<ReactNode> return type?
A: The view() method can return a Promise. The Component function checks if the result is a Promise and handles it appropriately, likely using Suspense boundaries or similar React patterns for async rendering.
Q9: How would the $chemistrify() function handle React component event handlers?
A: Event handler props (starting with on) would become $ prefixed methods on the Chemical. The function would detect these by type (Function) and name pattern, creating method properties that properly bind this context when called.
Q10: How does the prototype chain work when an instance becomes "detached" from its template?
A: Initially, instances use prototype properties. When bound or modified, Chemistry copies prototype properties to the instance (detaching). The instance can resetToTemplate() to delete instance properties and fall back to prototype, or even importStructure() to become a different type entirely (!).

                    return React.cloneElement(analysis.element!, {

                    });

                // Regular component - must wrap
                return React.createElement('div', {
                    'data-chem': this.cid,
                    style: { display: 'contents' }

                return React.createElement('div', {

        const constructor = (chemical as any)[this.constructorName];
        if (typeof constructor === 'function') {
            this.constructorInfo = this.parseConstructor(constructor);
        } else {
            this.constructorInfo = { paramCount: 0, hasRest: false };
        }
    }
    
    private parseConstructor(fn: Function): { paramCount: number; hasRest: boolean } {
        const match = fn.toString().match(/\(([^)]*)\)/);
        if (!match) return { paramCount: 0, hasRest: false };
        
        const params = match[1].split(',').map(p => p.trim()).filter(p => p);
        const hasRest = params.length > 0 && params[params.length - 1].startsWith('...');
        
        return { 
            paramCount: hasRest ? params.length - 1 : params.length, 
            hasRest 
        };
    }

        const [augmented, args] = this.processChildren(children, 0);
        this.collectedArgs = args;
        return augmented;
    }

        let changed = false;
        
        const augmented = React.Children.map(children, child => {
            if (!React.isValidElement(child)) {

                if (depth === 0) args.push(child);
                return child;
