Here's the full flow to get SSH commits working on Windows:
1. Generate an SSH key
Open Git Bash (or PowerShell) and run:
bash
ssh-keygen -t ed25519 -C "your_email@example.com"
Accept the default path (~/.ssh/id_ed25519) and set a passphrase if you want one.
2. Add the key to ssh-agent
bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
On Windows, if you're using PowerShell instead of Git Bash:
powershell
Get-Service -Name ssh-agent | Set-Service -StartupType Manual
Start-Service ssh-agent
ssh-add $env:USERPROFILE\.ssh\id_ed25519
3. Add the public key to GitHub
Copy it to clipboard:
bash
cat ~/.ssh/id_ed25519.pub | clip
Then go to GitHub → Settings → SSH and GPG keys → New SSH key, paste it in, and save.
4. Test the connection
bash
ssh -T git@github.com
You should see: Hi username! You've successfully authenticated...
5. Set your repo to use SSH
If you already cloned via HTTPS, switch the remote:
bash
git remote set-url origin git@github.com:USERNAME/REPO.git
For new clones, use the SSH URL from GitHub (git@github.com:...) instead of the HTTPS one.
6. Configure Git identity (if not done yet)
bash
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
After that, commits and pushes will authenticate via SSH automatically.
