Two separate limits are in play, and they don't work the way "buying credits extends my weekly limit" assumes.
The weekly "All models" bar at 100% is your included plan usage. Usage credits don't extend that bar — they bypass it. Once it's maxed, credits let you keep going at pay-as-you-go API rates instead of waiting for the Sunday 7 AM reset. So far so good, and credits do cover Claude Code: terminal and IDE usage draw from the same pool as chat.
The thing actually blocking you is the second bar: $40.38 spent / 101% used against a $40 monthly spend limit. That spend limit is a governor you set on how much credit can be drawn per month, and you've tripped it. It's not the same as your balance. You have $59.62 sitting there, but the $40/month cap is what's gating access to it — so the money's available, the cap just won't let you spend more of it this month.
The fix is the Adjust limit button next to "$40 Monthly spend limit." Raise it above ~$41 and Claude Code should work again immediately, drawing from your existing $59.62. Otherwise it stays blocked until the spend limit resets on Jul 1.
One thing to check if raising the cap doesn't unblock you: if you're using Claude Code non-interactively — the Agent SDK, claude -p scripts, or a GitHub Actions integration rather than typing in the terminal — that split into its own separate monthly credit pool as of June 15, with its own budget independent of this one. But for ordinary interactive terminal/IDE use, the monthly spend cap above is your constraint.
