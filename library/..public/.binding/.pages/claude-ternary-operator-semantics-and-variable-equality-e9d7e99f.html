Summary: The Five Structural Cases of R(x,y,t)
The ternary relation x =t> y partitions into exactly five cases based on how the three variables can be equal or distinct. This is exhaustive due to the transitivity of equality.
Case 1: All Distinct
text
s != r != o != s
Exemplar: sub =rel> obj
The canonical semantic pattern. Subject, relationship, and object are completely distinct. This is how we naturally parse "The mother loves her child" — three separate entities. From this case emerge the three foundational properties: subjecthood, objecthood, and relationship itself.
Key consequence: (sub,obj) == rel — the most specific relationship between subject and object is relationship itself.
Case 2: Subject Equals Relationship
text
s == r != o != s
Exemplar: sym =sym> lit
The subject is the relationship through which it relates. This captures symbolization: a symbol doesn't merely participate in symbolization—it is symbolization made concrete. The word "tree" both performs symbolizing and exists as the subject performing that act.
Key consequence: (sym,lit) == sym — symbolization is the most specific relationship between symbol and literal.
Case 3: Subject Equals Object
text
s != r != o == s    (equivalently: s == o != r)
Exemplar: can =rep> can
Subject and object coincide but the relationship remains external. This captures canonical representation: something represents itself through an external act of representation. The canonical serves as the privileged entry point—the canonical textbook, the canonical form of an equation.
Key consequence: Self-reference through external mediation. The canonical doesn't just be itself; it represents itself.
Case 4: Relationship Equals Object
text
s != r == o != s
Exemplar: sym =rep> rep
The relationship is the object being related to. This captures membership/containment: when we say "a dog is an animal," the category "animal" serves both as the relationship type (classification) and as the object (what the dog is classified as).
Key consequence: (sym,rep) == rep — representation is the most specific relationship, and symbols are members of representations.
Case 5: All Equal
text
s == r == o == s
Exemplars: eq =eq> eq, rel =rel> rel, ref =eq> ref
Complete coincidence. An entity serves simultaneously as subject, relationship, and object. This isn't reference (which requires representation) but constitutive relationship—semantic bedrock. Equality equals equality through equality; relationships relate through relationship.
Key consequence: These are grounding patterns that require no external support—the foundation from which other meanings build.
What I Notice Needs Rigor
The documents develop the exemplars well but leave some semantic questions open:
Properties and self-possession: Does sub =sub> sub? The documents flag this as an "open semantic question" with two interpretations (role-based vs inheritance-based).
