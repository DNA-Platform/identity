No, JavaScript Promises don't have a built-in property or method to check if they've resolved. Once you have a Promise reference, you can't synchronously query its state. This is by design - Promises are meant to be used with then(), catch(), or await.
However, there are workarounds to track Promise state:
Wrapper Pattern
javascript
class TrackablePromise {
    constructor(promise) {
        this.isPending = true;
        this.isResolved = false;
        this.isRejected = false;
        
        this.promise = promise
            .then(value => {
                this.isPending = false;
                this.isResolved = true;
                this.value = value;
                return value;
            })
            .catch(error => {
                this.isPending = false;
                this.isRejected = true;
                this.error = error;
                throw error;
            });
    }
}
For Chemistry's Use Case
For the async method deduping in Chemistry, you could track Promise state directly in the Formula:
typescript
class $Formula {
    private _promiseStates = new WeakMap<Promise<any>, 'pending' | 'resolved' | 'rejected'>();
    
    trackPromise(promise: Promise<any>) {
        this._promiseStates.set(promise, 'pending');
        
        promise
            .then(() => {
                this._promiseStates.set(promise, 'resolved');
            })
            .catch(() => {
                this._promiseStates.set(promise, 'rejected');
            });
            
        return promise;
    }
    
    isResolved(promise: Promise<any>): boolean {
        return this._promiseStates.get(promise) === 'resolved';
    }
}
Using Promise.race()
Another trick is using Promise.race() with an immediately resolved promise to check if something has settled:
javascript
const checkIfPending = (promise) => {
    const pending = Symbol('pending');
    return Promise.race([promise, Promise.resolve(pending)])
        .then(result => result !== pending);
};
For Chemistry's async handling, tracking the state explicitly when the promise is created (in bondCall) is probably the cleanest approach since you control the promise lifecycle from creation.

The $$ Run-Once Pattern
typescript
class $Chemical {
    private $$executed = new Set<string>();

            this.processing = false;
        }
