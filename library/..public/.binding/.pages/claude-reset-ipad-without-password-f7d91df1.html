Claude

Yes, a few official Apple methods work:
1. Erase from the lock screen (easiest, no computer) — On iPadOS 15.2+, after entering the wrong passcode 7+ times, you'll see "Erase iPad" in the bottom corner. Tap it, sign in with the Apple ID that's on the device, and it wipes itself. Requires internet and knowing the Apple ID password.
2. Recovery mode via computer — Connect to a Mac or PC with the cable, put the iPad in recovery mode (Face ID iPad: quick press Volume Up, quick press Volume Down, hold the Top button until the recovery screen appears; Home-button iPad: hold Home + Top together). Finder/iTunes will offer "Restore." This erases everything.
3. iCloud.com/find — From any browser, sign in with the Apple ID linked to the iPad, pick the device, choose "Erase This Device."
Important catch — Activation Lock: All three methods wipe the iPad, but if "Find My" was on, setup will demand the original Apple ID and password before the iPad is usable again. There's no Apple-supported way around this; it's the anti-theft system. Third-party "bypass" tools advertise around this but most don't work reliably on modern iPadOS, and some are scams.
If you don't have the Apple ID for it, the only legitimate path is an Apple Store visit with proof of purchase.

You're right — there isn't one. This is a real gap in Apple's parental controls.
The device passcode (lock screen PIN) is intentionally not resettable remotely, even by Apple themselves. It's the encryption key for everything stored locally on the device, baked into the secure enclave hardware. The only way to "reset" it is to wipe the device — which is exactly what you just spent the day doing. No surgical override exists from the parent side.
Apple does this on purpose. If the parent could remotely change the PIN, so could anyone who compromised the parent's Apple ID, and the whole device encryption model breaks. So they don't expose that lever at all.
Practical options going forward:
Set the passcode yourself during initial setup and share it with her, or pick something together you both know.
Disable changing the passcode via Screen Time → Content & Privacy Restrictions → Passcode Changes → Don't Allow. You'll need a Screen Time passcode (separate from the device PIN) that you set and she doesn't know. That blocks her from changing the device PIN later without your Screen Time PIN.
Don't use a passcode at all if the threat model is just "forgetful kid" rather than "device theft." Less secure but no lockout risk.
The Screen Time passcode lock on Passcode Changes is the actual answer to "how do I prevent this from happening again."
