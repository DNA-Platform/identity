DevUtils — The Product
DevUtils is a native macOS app that bundles 47+ small developer utilities into a single offline tool. JSON formatting, JWT debugging, Base64 encoding/decoding, regex testing, URL parsing, timestamp conversion, hash generation, and so on. The key design insight is that developers perform these micro-tasks dozens of times a day, and before DevUtils, the default behavior was to Google something like "JSON formatter online" and paste code into a random website. That workflow has two costs: it's slow (context-switching out of your editor, waiting for a browser tab to load, dealing with ads on sketchy utility sites), and it's a privacy leak — you're pasting potentially sensitive data into third-party web tools you don't control.
DevUtils solved both. It sits in your macOS menu bar, activates with a global hotkey, and does smart clipboard detection — meaning if you copy a JWT token, it automatically opens the JWT debugger. Everything stays on your machine. It launched at $9 one-time, and Tony built V1 in roughly two weeks after abandoning the over-engineered Log Viewer App that consumed six months.
Why DevUtils found a market: The pain was real, universal among developers, and recurring (you don't format JSON once; you do it multiple times per day). But critically, nobody had consolidated these tools into a single native app before. Individual web-based tools existed by the hundreds, but they were fragmented, ad-supported, and required network access. Tony's insight was a packaging innovation more than a technical one — the individual utilities aren't hard to build, but wrapping them into a cohesive offline macOS experience with smart detection was the product. The one-time purchase model also mattered. Developers were already annoyed at subscription fatigue; $9 (later raised) for a tool you'd use daily with zero ongoing cost was an easy yes.
Why he wasn't "first" to the utilities but was first to this packaging: Online JSON formatters, Base64 decoders, and JWT debuggers all existed. What didn't exist was a native, offline, consolidated macOS toolbox with clipboard-aware auto-detection. That's the distinction — he didn't invent the category of "developer utilities," he invented the form factor. The analogy would be: Swiss Army knives didn't invent the blade, the screwdriver, or the can opener. They invented putting them together in your pocket.
The initial distribution came from a Hacker News post that went viral for two days. DevUtils peaked at about $20K/month early on and as of 2025 still generates around $8K/month on autopilot. TypingMind — The Product
TypingMind is a frontend UI for interacting with LLMs (originally ChatGPT, now supporting Claude, Gemini, Llama, and others) using your own API keys. You pay a one-time license fee for the interface, then bring your own API key so you only pay for actual token usage — no $20/month ChatGPT Plus subscription, no arbitrary message caps.
The origin story is precise and instructive. TypingMind was released just five days after OpenAI announced the ChatGPT API. Tony registered the domain on March 2, 2023, shipped the MVP on March 6, and by March 10 had done $10K in revenue. The specific pain points he was solving: ChatGPT's web interface forced you to re-login constantly, typed responses slowly (streaming wasn't optimized), and had no way to search past conversations. These sound minor, but for someone using ChatGPT heavily every day — which Tony was — they compounded into serious friction.
The pricing trajectory is worth tracking. It launched at $9 one-time. He gradually raised it. Current pricing includes a Standard plan at $39, Extended at $79, and Premium at $99–198, all one-time. You're raising a legitimate question, and the confusion comes from a couple of specific misunderstandings about what the API actually is versus what the browser ChatGPT experience is. Let me untangle them.
The API gives you the same models, not worse ones. GPT-4o via the API is the same GPT-4o you get in the browser. GPT-4.5, o1, o3 — same models. The API isn't a degraded version of ChatGPT. It's the raw model access that ChatGPT's own web interface is built on top of. When you use ChatGPT in a browser, OpenAI's frontend is making API calls to the same backend. So TypingMind users aren't getting a lesser model — they're getting the identical model with a different interface wrapped around it.
The API is actually cheaper for most usage patterns, not more expensive. This is the core economic insight of the whole business. ChatGPT Plus costs $20/month (now $25 with Pro at $200). That's a flat fee regardless of how much you use it. API pricing is per-token — you pay only for what you consume. For a typical user sending maybe 50-100 messages a day, API costs might run $3-8/month depending on the model. For a lighter user, maybe $1-2/month. The $20/month subscription is actually overpriced for the majority of users relative to their actual token consumption. OpenAI prices it that way because flat subscriptions are easier to sell and capture surplus from light users.
So the TypingMind pitch was: pay $39 once for my interface, then pay $3-8/month in API costs instead of $20/month to OpenAI. Over a year, you save money. Over two years, you save a lot of money.
Now, the memory and context point — this is where your instinct is partially right.
ChatGPT's web interface has added features that the raw API doesn't give you for free: persistent memory across conversations, custom GPTs, the ability to upload files to a persistent knowledge base, browsing, code interpreter, DALL-E integration, and so on. These are application-layer features that OpenAI built on top of the API. When you use the API directly, you don't automatically get "memory" — you get a stateless endpoint where you send messages and get responses. Each API call is independent unless you manage the conversation history yourself.
This is exactly what TypingMind does. It stores your conversation history locally (on your device), manages context windows, lets you search past conversations, organize chats into folders, define custom AI characters with system prompts, and so on. It's rebuilding those application-layer features — in some cases better than ChatGPT's native UI (search was terrible in ChatGPT for a long time), in some cases not as deeply integrated (OpenAI's built-in memory system that persists facts across conversations is harder to replicate externally).
So who is still paying for TypingMind in 2025 when ChatGPT's native interface has gotten so much better?
The answer has shifted over time, and this is the honest version:
In March 2023 when TypingMind launched, ChatGPT's interface was genuinely bad — no search, constant logouts, slow streaming, no conversation organization. TypingMind was dramatically better for individual power users. That's where the initial wave of one-time purchases came from.
By late 2023 and into 2024, ChatGPT's own interface improved significantly. The individual consumer value proposition narrowed. But TypingMind pivoted its growth engine toward B2B and teams. The self-hosted "Custom Deployment" product lets a company deploy TypingMind on their own infrastructure, connect it to their own API keys, control which models employees can access, set usage limits, and keep all data internal. This is valuable to enterprises that want to give employees AI access without routing sensitive data through OpenAI's consumer product. That's a very different market than individual power users, and it's where the recurring revenue growth is coming from.
The other ongoing individual use case is model-agnostic access. TypingMind isn't locked to OpenAI — you can plug in Claude, Gemini, Llama, and other model APIs in the same interface, switch between them mid-conversation, compare outputs. If you use multiple AI providers, having one unified interface with one conversation history across all of them is genuinely useful in a way that ChatGPT's native interface (which only serves OpenAI models) can't offer.
To directly answer "does it still make money": yes, but the reason it makes money has evolved. The initial wave was individual consumers fleeing a bad ChatGPT UI. The current wave is teams and enterprises wanting controlled, self-hosted, multi-model AI access. The one-time purchase model for individuals still generates revenue from new buyers, but the growth story is now B2B subscriptions layered on top.
Your instinct that the individual consumer case has gotten weaker over time is correct. But Tony didn't need it to stay strong forever — he used the initial revenue surge to fund development of the enterprise features that now drive growth on a different value proposition entirely.
