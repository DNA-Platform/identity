Universality. The finite claim is provable.
srt
Theorem. Any finite structure (finitely many things,
finitely many relations of any arity, repetition
allowed) is represented in a finite domain.

Uses: Sketch representation block, individuality,
uniqueness of the pair, no function symbols.

1. Things. One referent ai each. Individuality gives
   ai =ai> ai and (ai,ai) == ai, so no new referents.
2. Tuples. Each tuple of P becomes an array T:
   cells ck in T, ck =s> ck+1, ck =ck> ak, T in P.
   Repeated entries are distinct cells.
3. Pairs. For each related pair, (x,y) is the
   collapse where the pair collapses, else one fresh
   referent. Uniqueness holds because each is fresh.
4. Closure. A new line x =(x,y)> y reuses its pair.
   The line ck -> T, i.e. ck =T> ck, uses (ck,ck),
   which individuality absorbs. Nothing further is
   forced, so the domain is finite.
5. Reading. P holds of (a1..an) iff some T in P has
   cells, in s-order, referring to a1..an. Distinct
   tuples differ at some cell.
The computer. A machine state is a finite structure: memory cells in order, each referring to 0 or 1, plus the head and the control state. By the theorem it is representable. The transition table is finite, so it is representable too. A halting run is an array of states whose successor is the step, so it is also representable.
What the theorem doesn't cover is producing state k+1 from state k. That is a transduction: asserting the next representation. An unbounded tape is the same open frontier as the whole numbers, named as it is needed.
So the universality is exactly a computer's. Everything that exists at any moment is finite, and the system is unbounded only in its going.

Why Henkin and not Skolem. Skolem would handle the same existential with a function, next(S), and the step would be a term. Two differences from Henkin.
text
  Henkin: iterate ω times, take the union, extend
          to a maximal consistent theory (Lindenbaum),
          build the model from the constants.
  SRT:    no union is ever taken. Each stage is finite.
          The going continues or stops; there is no

The first difference is that the union is never taken. Henkin needs the completed ω-chain because his goal is completeness. SRT needs only the next stage, which fits referability being time-indexed and never a completed set.
The second is what the model is made of. Henkin's model is built from syntax: the constants are terms, and the model is made of names. In SRT the minted symbol is already a referent in the domain, so the model is the theory itself. The model isn't constructed alongside it; it grows by transduction. This is library semantics in its sharpest form: the book is the model it describes.
Continuing or ending. Ending is simply the absence of the existential. If δ licenses no step from S_k, T_k carries no line of the form E[s]: S_k =step> s, so there is nothing to name, and the run halts. A run that never halts has the existential at every stage, which is Henkin's ω-chain, lived one step at a time and never finished.
