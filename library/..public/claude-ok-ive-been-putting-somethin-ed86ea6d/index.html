Two approaches that work well together — discovery sources (to surface every account that exists) and a category checklist (to make sure you don't miss whole buckets).
Discovery sources — go through each and write down anything with your old address:
Password manager (biggest single source if you use one)
Email search for "address," "shipping to," "change of address," "billing statement"
Last 12 months of credit card and bank statements (catches subscriptions and recurring billers)
Browser autofill profiles
Physical mail forwarded by Traveling Mailbox over the last 6 months
Contacts app (doctors, accountants, attorneys you'd tell personally)
Category checklist — to sanity-check you've covered everything:
Government: IRS (Form 8822), state tax authority (last state of residence), Social Security Administration, State Department / passport records if you use a US address for consular stuff, voter registration (federal absentee via FVAP if you still want to vote), Selective Service if applicable
Financial: every bank, brokerage, credit card, retirement account (401k, IRA custodians), HSA, 529, crypto exchanges, PayPal/Wise/Mercury, any closed accounts still sending tax forms
Insurance: health, dental, life, umbrella, renters, any US auto policy still active
Investment/fund admin: K-1 issuers, any private investments, fund admins for LPs
Employment/income: current and past employers (for W-2s), any 1099 payers
Professional: LinkedIn, professional associations, alumni (UChicago, UCSD), licenses
Healthcare: every US doctor/dentist/specialist, pharmacies, medical records holders
Legal/estate: attorneys, estate documents (if you have a will listing your address)
Loyalty/travel: airline programs, hotel programs, TSA PreCheck/Global Entry, credit card travel portals
Subscriptions: streaming, software, news, anything recurring
Shipping/delivery: Amazon, any regular vendors
Two things to flag specifically for your situation:
Some US financial institutions won't let you have a foreign residence on file even if mailing goes to NC — they ask for residence address separately. Decide in advance whether you're declaring Georgia as your residence or keeping NC as both. This affects state tax residency too.
Brokerages (IB, Schwab, Fidelity) often restrict account activity when they detect a non-US residence. Worth knowing which of yours are OK with a true non-resident and which you're effectively keeping on an NC-resident fiction.
Want me to build this as an actual tracking spreadsheet (one row per account, columns for status/date updated/notes)? That's probably the most useful next step if you're going to work through it over days or weeks.

You're right on both pushbacks, and the Chrome point is a genuinely good catch.
On Chrome/autofill: Yes — Chrome, Apple (iCloud Keychain/Wallet), and any other browser/OS autofill profiles should befirst on the list, not omitted. If you update those first, every subsequent web form pre-fills correctly and you stop propagating the old address by accident. Same logic for Amazon's saved addresses, PayPal's saved addresses, etc. — these are "address sources" that feed other transactions.
On passport: You're right, I was wrong. The State Department uses the address from your most recent passport application. There's no separate "update my address with State" process for a regular citizen — it happens at renewal. Remove it. (The exception is if you're enrolled in STEP, the Smart Traveler Enrollment Program, which does have its own address — but that's opt-in and you'd know if you did it.)
On IRS: Partially right. If you file your next return with the new address, the IRS updates automatically — Form 8822 is only needed if you've moved between filings and expect correspondence (refund check, notice) in the interim. Given you've already sold the house, the question is whether anything is in flight right now. If not, just file your next return with the new address and skip 8822.
On state tax: Same logic as IRS — handled at next filing. But there's a bigger question underneath: which state are you a resident of now? If you're claiming NC via the mailbox, that's a residency position, not just an address. Worth thinking about separately from this checklist.
