The issue is in the chaining of the methods. In your close() method, you're calling this.closed(true) but not doing anything with the return value. ExtendScript/JavaScript functions that don't explicitly return a value will return undefined.
The close() method immediately returns this after calling closed(true), but since you're not capturing or using the boolean return value from the closed() method, it appears as undefined in your logs.
Here's how you could fix it:
typescript
closed(close?: boolean): boolean {
    console.log("closed param", close);
    if (close !== undefined) {
        this._closed = close;
        this.onChange().fire(this);
    }
    return this._closed;
}

close(): this {
    console.log("Closing");
    const isClosed = this.closed(true); // capture the return value if needed
    // or just call it without capturing: this.closed(true);
    return this;
}

open(): this {
    this.closed(false);
    return this;
}
The undefined you're seeing is likely because you're trying to use the return value of close() as a boolean, but it returns this for method chaining. If you need the boolean value, you should call the closed() method directly or store its result before returning this.
If you're trying to check if something is closed, you should use:
typescript
const isClosed = instance.closed(); // gets the current state
Rather than:
typescript
const isClosed = instance.close(); // returns 'this' for chaining
