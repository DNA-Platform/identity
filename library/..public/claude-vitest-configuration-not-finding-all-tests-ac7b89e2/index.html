Based on your project structure, the issue is clear: your test file naming pattern doesn't match what Vitest is looking for.
The Problem
✅ particle.test.ts - uses .test.ts (singular) - runs
❌ catalogue.tests.ts - uses .tests.ts (plural) - doesn't run
Vitest by default looks for files matching patterns like:
*.test.ts
*.spec.ts
*.test.tsx
*.spec.tsx
But NOT *.tests.ts (with the extra 's').
Solution Options
Option 1: Rename the file (simplest)
Rename catalogue.tests.ts to catalogue.test.ts
Option 2: Update your vitest config
Add a custom include pattern to your vitest.config.ts to catch both patterns:
typescript
import { defineConfig } from 'vitest/config'
import path from 'path'

export default defineConfig({
  test: {
    globals: true,
    environment: 'happy-dom',
    include: ['**/*.{test,tests,spec}.{js,mjs,cjs,ts,mts,cts,jsx,tsx}'],  // Added 'tests' pattern
    deps: {
      inline: [/chemistry/]
    }
  },
  resolve: {
    extensions: ['.tsx', '.ts', '.jsx', '.js'],
    alias: {
      '@': path.resolve(__dirname, './src'),
    }
  },
  esbuild: {
    target: 'node14'
  }
})
I'd recommend Option 1 - just rename the file to catalogue.test.ts for consistency with your other test files.
