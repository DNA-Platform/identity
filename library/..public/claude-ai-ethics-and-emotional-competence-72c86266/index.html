Here's a rough template:
"Use the web. Search for [topic]. List what sources report about [specific question]. Include source URLs. Bullet points, no synthesis."
The key moves:
"Use the web" — you've already found this triggers search reliably.
"What sources report" — frames the task as retrieval, not judgment. You're not asking GPT what's true; you're asking what's out there. This might reduce the impulse to editorialize.
"Include source URLs" — forces attribution, which both gives you something to verify and keeps the system honest about where claims originate.
"Bullet points, no synthesis" — discourages the interpretive framing where the trouble lives. You want raw material, not a narrative.
"No analysis needed" or "Report only" — explicitly closes the door on the system deciding to add value through interpretation.
You might also try:
"What are the primary sources saying about [X]? List claims with attribution. I'll do my own synthesis."
That last sentence signals that you're not asking for help thinking—you're asking for ingredients. It might reduce the posture of "let me help you understand this."
Worth testing whether these actually change GPT's behavior or whether the patterns are too deep. But it's a starting point.
