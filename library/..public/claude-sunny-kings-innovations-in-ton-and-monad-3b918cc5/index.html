This is a great question that connects nicely to your broader research on cryptocurrency infrastructure lineages. Let me break down how these innovations flow through different projects.
Sunny King's Core Innovations
Sunny King invented proof-of-stake consensus with Peercoin in August 2012 to break the Bitcoin blockchain's linkage to power consumption. His key contributions include:
Proof-of-Stake (PoS) - The fundamental alternative to PoW where coin ownership replaces computational work
Coin Age - A concept derived from multiplying the amount of coins a minter owns by the number of days those coins have been held in their wallet
Peercoin (2012) - First PoS cryptocurrency
Primecoin (2013) - The first research coin with a useful PoW, with consensus based on computing chains of prime numbers
Supernode PoS (SPoS) - His 2018 evolution for V Systems
What is VSYS?
V Systems is an open-source network that supports efficient development of decentralized applications, designed by Sunny King with a team of 40+ experts. It's powered by Supernode Proof of Stake (SPoS), a new consensus mechanism that outperforms PoS in efficiency, security, and cost-effectiveness.
Key SPoS innovations:
Sixty total slots are available to Supernodes, each corresponding to a specific second within a minute. Block minting is awarded by merely being next in line rather than playing a game of crypto lottery.
Supernode status can be contended at any time via a process that assesses and compares minting average balance, fostering hardware-focused competition between supernodes.
Coin leasing system where regular holders lease to supernodes and earn returns
How TON Handles King's Innovations
TON builds on the PoS foundation but combines it with Byzantine Fault Tolerance:
TON employs a Byzantine Fault Tolerant (BFT) Proof-of-Stake consensus mechanism, which enhances both security and scalability. Validators are required to stake a minimum of 300,000 TON to participate in the consensus process.
TON's approach differs from King's pure PoS in that:
It adds BFT for instant finality (no probabilistic confirmation)
Uses sharding (masterchain + workchains + shardchains) for scalability
Higher validator stake requirements
No coin-age weighting like Peercoin
TON doesn't use King's "useful work" concept from Primecoin - the consensus is purely about stake, not about generating mathematically interesting artifacts.
Does Monad Handle These Things?
Monad is a proof-of-stake Layer 1 blockchain that introduces parallel transaction processing and a pipelined consensus mechanism.
Monad uses MonadBFT, a pipelined, Proof-of-Stake Byzantine Fault Tolerant consensus mechanism inspired by HotStuff. In this design, block proposal, voting, and finalization happen in parallel.
Monad is a delegated Proof of Stake (dPoS) layer 1, with validators responsible for proposing and finalizing blocks, their influence determined by the amount of MON staked (inclusive of self stake and delegated stake).

Why Peercoin needed PoW:
The problem with Peercoin is that it fails to give incentives to token holders to decisively opt for a single chain. Instead they can break security by voting for multiple conflicting blocks without incurring any cost to do so.
This is the famous "nothing at stake" problem. In many early (all chain-based) proof of stake algorithms, including Peercoin, there are only rewards for producing blocks, and no penalties.
How BFT solves it elegantly:
Accountability allows us to penalize malfeasant validators, solving the "nothing at stake" problem that plagues chain-based PoS. The penalty for violating a rule is a validator's entire deposit. This maximal penalty is the defense against violating the protocol. Because proof of stake security is based on the size of the penalty, which can be set to greatly exceed the gains from the mining reward, proof of stake provides strictly stronger security incentives than proof of work.
So yes - BFT-PoS is the perfected form of Peercoin's vision. Peercoin needed PoW as training wheels to provide economic finality. BFT provides that finality through slashing conditions instead.
On Primecoin Insights
This is a more subtle question. Primecoin's core insight was: if you're going to do computational work, make it produce something mathematically valuable (finding prime chains).
The modern successor to this concept is Verifiable Delay Functions (VDFs) - VDFs are functions that require a moderate amount of sequential computation to evaluate, but once a solution is found, it is easy for anyone to verify that it is correct.
VDFs are used in some blockchains for:
Randomness beacons (unpredictable leader selection)
Proof of replication (storage networks)
Preventing front-running
Does TON use Primecoin-style useful work?
From what I can find, TON does not directly incorporate useful work or VDFs in its core consensus. TON's BFT-PoS is pure economic staking + voting without computational puzzles.

Peercoin → "PoS can replace PoW"
