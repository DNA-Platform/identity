Complete helper for getting and setting:
typescript
function getPropertyValue(obj: any, prop: string): any {
    const desc = Object.getOwnPropertyDescriptor(obj, prop);
    if (!desc) return undefined;
    
    return desc.get ? desc.get.call(obj) : desc.value;
}

function setPropertyValue(obj: any, prop: string, value: any): void {
    const desc = Object.getOwnPropertyDescriptor(obj, prop);
    
    if (!desc) {
        // Property doesn't exist - create it
        obj[prop] = value;
        return;
    }
    
    if (desc.set) {
        // Use the setter
        desc.set.call(obj, value);
    } else if (desc.writable) {
        // Direct assignment for writable property
        desc.value = value;
        Object.defineProperty(obj, prop, desc);  // Update the descriptor
    } else {
        throw new Error(`Cannot set read-only property '${prop}'`);
    }
}
Note: For regular properties, you can either:
Set obj[prop] = value directly
Or modify desc.value and redefine the property with Object.defineProperty()
Both work, but the direct assignment is simpler for regular properties.

You can create a property on an object in several ways:
1. Direct assignment (simplest):
typescript
const obj = {};
obj.newProp = 'value';
obj['anotherProp'] = 42;
2. Object.defineProperty() (most control):
typescript
Object.defineProperty(obj, 'counter', {
    value: 0,
    writable: true,      // Can be changed
    enumerable: true,    // Shows in for...in
    configurable: true   // Can be deleted/redefined
});

// With getter/setter
Object.defineProperty(obj, 'computed', {
    get() { return this._internal * 2; },
    set(val) { this._internal = val / 2; },
    enumerable: true,
    configurable: true
});
3. Object.defineProperties() (multiple at once):
typescript
Object.defineProperties(obj, {
    prop1: { value: 'first', writable: true },
    prop2: { value: 'second', writable: false },
    getter: { 
        get() { return 'computed'; }
    }
});
4. Spread/Object.assign():
typescript
// Spread
const newObj = { ...obj, newProp: 'value' };

// Object.assign
Object.assign(obj, { newProp: 'value' });
Key differences:
Direct assignment: Creates enumerable, writable, configurable properties
defineProperty: Gives full control over property attributes
Spread/assign: Copies enumerable properties only
For your Chemistry framework, you'd likely use defineProperty when creating reactive properties to control their behavior precisely.

typescript
class Example {

    myMethod() {
        return 'hello';
    }
    
    // Getter on prototype
    get myGetter() {
        return 'world';
    }
}

const instance = new Example();

// Check the prototype
const methodDesc = Object.getOwnPropertyDescriptor(Example.prototype, 'myMethod');
console.log(methodDesc);
// { value: [Function: myMethod], writable: true, enumerable: false, configurable: true }

const getterDesc = Object.getOwnPropertyDescriptor(Example.prototype, 'myGetter');
console.log(getterDesc);
// { get: [Function: get myGetter], set: undefined, enumerable: false, configurable: true }
Key differences:
Methods: Have a value property containing the function, are writable: true
Getters: Have a get property with the getter function, no value property
So for methods:
typescript
// You can read it
const fn = methodDesc.value;  // The function itself

// You can call it
const result = methodDesc.value.call(instance);

// You can even reassign it (since writable: true)
Example.prototype.myMethod = function() { return 'changed'; };
Methods are just regular properties that happen to contain functions, while getters/setters are special accessor properties.
