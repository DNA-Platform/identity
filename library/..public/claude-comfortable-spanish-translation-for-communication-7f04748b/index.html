When you combine overlapping SVG paths, the behavior depends on the specific operation you use:
Unite/Merge (Pathfinder Unite):
Creates a single path from overlapping shapes
Maintains vector properties
Preserves the outermost edges
Interior overlapping segments are removed
Remains fully SVG-compatible
Compound Path (Command/Ctrl + 8):
Keeps paths separate but treats them as one unit
Interior overlaps become "holes"
Still remains vector
Fully SVG-compatible
Neither operation should cause any SVG compatibility issues since they're both pure vector operations. SVG handles both unified paths and compound paths very well.
If you're seeing issues, check:
Were the paths perfectly aligned when combined?
Are there any tiny fragments or artifacts from the combination?
Try ungrouping (Shift + Command/Ctrl + G) and recombining
Use "Clean Up" command to remove stray points
What specific behavior are you seeing with the combined paths in your SVG?
