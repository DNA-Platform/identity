SVG Paths and Their Structure
SVG paths are defined using the <path> element with a d attribute containing a series of commands and coordinates that define the path's shape.
Path Commands
M/m (Move): Moves to a new position without drawing (M for absolute coordinates, m for relative)
L/l (Line): Draws a straight line to specified coordinates
H/h (Horizontal Line): Draws a horizontal line
V/v (Vertical Line): Draws a vertical line
C/c (Cubic Bézier): Creates a cubic Bézier curve using two control points
S/s (Smooth Cubic Bézier): Creates a cubic Bézier with one control point (the other is reflected)
Q/q (Quadratic Bézier): Creates a quadratic Bézier curve with one control point
T/t (Smooth Quadratic Bézier): Creates a quadratic Bézier curve with an implicit control point
A/a (Arc): Creates an elliptical arc
Z/z (Close): Closes the path by connecting back to the starting point
Anchor Points
Anchor points (also called nodes) are the key points that define a path:
Corner points: Where two line segments meet at an angle
Smooth points: Where the path passes through continuously with matching tangents
Symmetrical points: Special smooth points where control handles are equidistant
Control Points
Control points determine the curvature of Bézier curves but don't lie on the path itself. They act like "magnets" pulling the path toward them.
Bézier Curves in Detail
Cubic Bézier Curves
A cubic Bézier curve requires four points:
Starting point (P0)
Two control points (P1, P2) that define the curvature
Ending point (P3)
The path is defined parametrically as: B(t) = (1-t)³P0 + 3(1-t)²tP1 + 3(1-t)t²P2 + t³P3, where t ∈ [0,1]
In SVG, a cubic Bézier is written as: C x1 y1, x2 y2, x y where (x1,y1) and (x2,y2) are the control points and (x,y) is the end point.
Quadratic Bézier Curves
A simpler curve with just one control point:
Starting point (P0)
One control point (P1)
Ending point (P2)
The parametric equation is: B(t) = (1-t)²P0 + 2(1-t)tP1 + t²P2, where t ∈ [0,1]
In SVG, it's written as: Q x1 y1, x y
Advanced Path Techniques
Path Smoothing
Catmull-Rom splines convert a series of points into a smooth curve by calculating appropriate control points. Unlike Bézier curves, Catmull-Rom splines actually pass through all the specified points, making them useful for smoothing hand-drawn paths.
Path Manipulation
Programmatically, you can:
Split paths: Break a complex path into simpler segments
Join paths: Combine multiple paths with appropriate control points
Resample paths: Add or remove points for smoother curves or optimization
Normalize paths: Adjust control points for consistent curvature
