The tools that bring my conversations into this library, one chapter to a stage and the code that runs the stage beside it, so that how a conversation gets in can be read beside the thing that does it. A conversation comes in as a conversation, the type of book kept in the reference manual for it, and every source is read into one record, so that a second source is one more reader and nothing else moves. Start with The Importer, which runs the stages in order and reports what it did, and then The Export, which says what is read and where it is found.
The Importer
The run: the stages in order, from an export on disk to conversations filed in this library, and the report of what it did.
Nine stages and nothing hidden between them
A conversation gets into this library in stages, and each stage is a chapter of this book with its code beside it, so a change to the code is never a question about which page owes an edit. The importer finds the export where it lands, reads it into one record, pairs each conversation to its project by evidence, asks the ledger which conversations are new, walks the thread that was on the screen, turns what was said into writing, writes the books, and checks what it wrote against the archive the export was first read into.
Run bare it says what it would write and stops. Run to write it writes, and reports: the conversations found, paired, unpaired, ambiguous and excluded; the messages on the screen and on other paths; the files written. It takes a project's worth at a time, never the whole export in one run, so the library grows at the pace the bind is measured to bear. While the importer is being made it overwrites what it wrote, on a flag said at the run; once it is done it never does, since a conversation once imported is edited by hand.

export const parsedArguments = (argv: string[]): Arguments => ({
    projectName: flagValue(argv, '--project'),
    onlyTitle: flagValue(argv, '--only'),
    intoFolder: flagValue(argv, '--into'),

export const run = async (args: Arguments): Promise<void> => {
    const reading = await exportReading();
    const pairings = conversationPairings(args.library, reading.conversations, reading.projects, reading.mapping);
    console.log(pairingReport(pairings));
    if (args.projectName === undefined) {
        if (!args.write) console.log('nothing written — pass --write with --project');
        return;
    }
    const projectPairings = pairings.filter(pairing => pairing.projectName === args.projectName);
    const conversationOfPairing = (pairing: Pairing): Conversation =>
        reading.conversations.find(conversation => conversation.id === pairing.conversationId)!;
    const folders: LibraryFolders = {
        library: args.library,
        claude: join(args.library, '.claude'),
        claudeManual: join(args.library, '.claude', '.manual'),
        conversations: join(args.library, '.claude', '.conversations'),
    };
    const heldRecords = importRecords(folders.conversations);
    listProjectConversations(args.projectName, projectPairings, conversationOfPairing, folders, heldRecords);
    const pairedConversations = projectPairings.filter(pairing => !pairing.excluded).map(conversationOfPairing);
    console.log(archiveCheckReport(args.projectName, reading, pairedConversations));
    console.log(differenceLines('written back against the export', writtenDifferences(
        pairedConversations, heldRecords, folders.conversations,
    )).join('\n'));
    const chosenConversations = projectPairings
        .filter(pairing => !pairing.excluded && (args.onlyTitle === undefined || pairing.title === args.onlyTitle))
        .map(conversationOfPairing);
    if (args.intoFolder !== undefined) {
        for (const conversation of chosenConversations)
            writeChapterIntoFolder(args.intoFolder, conversation);
        return;
    }
    if (!args.write) {
        console.log('\nnothing written — pass --write');
        return;
    }
    const project = reading.projects.find(candidate => candidate.name === args.projectName);
    if (project === undefined) throw new Error(`no project named ${args.projectName} in the export`);
    writeProjectBooks(args, folders, project, reading, chosenConversations, heldRecords);
};

const exportReading = async (): Promise<ExportReading> => {
    const started = Date.now();
    const source = exportSource(accountFolder);
    console.log(`reading ${source.name}`);
    const projects = source.projects();
    const documentCount = projects.reduce((total, project) => total + project.documents.length, 0);
    const namedProjectCount = projects.filter(project => project.name !== '').length;
    const memoryFileCount = source.memories().length;
    console.log(`  ${countedNoun(projects.length, 'project')}, ${namedProjectCount} named, `
        + `${countedNoun(documentCount, 'document')}, ${countedNoun(memoryFileCount, 'memory file')}`);
    const mapping = source.mapping();
    console.log(mapping === undefined ? noMappingWords : mappingReport(mapping));
    const conversations: Conversation[] = [];
    const blockCounts = new Map<string, number>();
    for await (const conversation of source.conversations()) {
        conversations.push(conversation);
        for (const message of conversation.messages)
            for (const block of message.blocks)
                blockCounts.set(block.type, (blockCounts.get(block.type) ?? 0) + 1);
    }
    const messageCount = conversations.reduce((total, conversation) => total + conversation.messages.length, 0);
    const blockCountWords = [...blockCounts.entries()].map(([blockType, count]) => `${count} ${blockType}`).join(', ');
    console.log(`  ${countedNoun(conversations.length, 'conversation')}, ${countedNoun(messageCount, 'message')}: `
        + blockCountWords);
    console.log(`read in ${elapsedSeconds(started)}`);
    const counts: ExportCounts = {
        conversationCount: conversations.length,
        messageCount,
        projectCount: projects.length,
        documentCount,
        contentfulCount: conversations.filter(conversation => conversation.messages.length > 0).length,
    };

    return { exportedOn: source.exportedOn, projects, mapping, conversations, counts };
};

const archiveCheckReport = (projectName: string, reading: ExportReading, pairedConversations: Conversation[]): string => {
    const statisticsPath = join(accountFolder, '.statistics.md');
    if (!existsSync(statisticsPath)) return '\nno archive to check against';
    const statistics = archiveStatistics(readFileSync(statisticsPath, 'utf8'));
    const transcripts = archiveTranscripts(accountFolder);
    const filedNames = archiveFiling(accountFolder, projectName);
    const filingLines = filedNames === undefined
        ? [`filing: the archive has no project named ${projectName}`]
        : differenceLines('filing', filingDifferences(pairedConversations, filedNames, transcripts));

    return [
        '',
        `checked against the archive, ${countedNoun(transcripts.size, 'transcript')}`,
        ...differenceLines('counts', countDifferences(reading.counts, statistics)),
        ...filingLines,
        ...differenceLines('messages', transcriptDifferences(pairedConversations, transcripts)),
    ].join('\n');
};

const mappingReport = (mapping: Mapping): string => {
    const filedCount = mapping.projects.reduce((total, mappedProject) => total + mappedProject.conversations.length, 0);

    return `  the mapping of ${mapping.capturedAt.slice(0, 10)}: ${countedNoun(mapping.projects.length, 'project')}, `
        + `${countedNoun(filedCount, 'conversation')} filed`;
};

const pairingReport = (pairings: Pairing[]): string => {
    const pairingCount = (test: (pairing: Pairing) => boolean): number => pairings.filter(test).length;

    return [
        `paired ${pairingCount(pairing => pairing.projectName !== undefined && !pairing.excluded)}`,
        `unpaired ${pairingCount(pairing => pairing.projectName === undefined && !pairing.excluded)}`,
        `ambiguous ${pairingCount(pairing => pairing.evidence.startsWith('ambiguous'))}`,
        `excluded ${pairingCount(pairing => pairing.excluded)}`,
        `by hand ${pairingCount(pairing => pairing.byHand)}`,
    ].join(' · ');
};

const listProjectConversations = (
    projectName: string,
    projectPairings: Pairing[],
    conversationOfPairing: (pairing: Pairing) => Conversation,
    folders: LibraryFolders,
    heldRecords: Map<string, HeldRecord>,
): void => {
    const includedPairings = projectPairings.filter(pairing => !pairing.excluded);
    const byHandCount = includedPairings.filter(pairing => pairing.byHand).length;
    const byHandWords = byHandCount > 0 ? `, ${byHandCount} by hand` : '';
    console.log(`\n${projectName}: ${countedNoun(includedPairings.length, 'conversation')} paired${byHandWords}`);
    for (const pairing of includedPairings) {
        const conversation = conversationOfPairing(pairing);
        const path = shownPath(conversation);
        const record = heldRecords.get(conversation.id)?.record;
        const stateWord = importState(conversation, folders.conversations, record).padEnd(6);
        const shownWords = `${path.length} shown of ${conversation.messages.length}`;
        const countWords = `${shownWords}, ${asideCount(conversation, path)} aside`;
        const dayWords = countedNoun(pathDays(path).length, 'day');
        const nameWords = conversation.name || 'Untitled';
        console.log(`  ${stateWord} ${nameWords} · ${countWords} · ${dayWords} · ${pairing.evidence}`);
    }
    for (const pairing of projectPairings.filter(pairing => pairing.excluded))
        console.log(`  out    ${pairing.title} · ${pairing.reason}`);
};

const writeChapterIntoFolder = (intoFolder: string, conversation: Conversation): void => {
    const manualImportPath = '../.manual/.book';
    const claudeManualImportPath = '../.claude/.manual/.book';
    const path = shownPath(conversation);
    const chapter = writtenChapter(conversation, path, referents, manualImportPath, claudeManualImportPath);
    const folder = join(intoFolder, slugFromName(conversation.name));
    mkdirSync(folder, { recursive: true });
    writeFileSync(join(folder, chapter.fileName), chapter.tsx, 'utf8');
    for (const chapterFile of chapter.files)
        writeFileSync(join(folder, chapterFile.name), chapterFile.content, 'utf8');
    const fileWords = countedNoun(chapter.files.length, 'file');
    const thinkingWords = countedNoun(chapter.thinkingCount, 'thinking block');
    const resultWords = countedNoun(chapter.resultCount, 'result');
    const reportWords = `${fileWords} beside it, ${thinkingWords} and ${resultWords} left out`;
    console.log(`\nwrote ${join(folder, chapter.fileName)} with ${reportWords}`);
};

const writeProjectBooks = (
    args: Arguments,
    folders: LibraryFolders,
    project: Project,
    reading: ExportReading,
    chosenConversations: Conversation[],
    heldRecords: Map<string, HeldRecord>,
): void => {
    const filesTouched: string[] = [];
    const dougsClaudeFiles = registerBook(
        folders, folders.claude, 'Dougs Claude', 'Claude', 'Library', 'The Library',
        wrappedLines(dougsClaudeSynopsis), schemes[5], args.overwrite,
    );
    const ourConversationsFiles = registerBook(
        folders, folders.conversations, 'Our Conversations', 'Conversations', 'Claude', 'Dougs Claude',
        wrappedLines(ourConversationsSynopsis), schemes[1], args.overwrite,
    );
    const ourConversationsEntry = registerEntry(
        folders, folders.claude, 'Our Conversations', folders.conversations, new Date().toISOString(),
        ourConversationsCaption, '**',
    );
    const dougsClaudeEntryFiles = libraryEntry(folders.library, 'Dougs Claude', folders.claude, dougsClaudeCaption);
    filesTouched.push(...dougsClaudeFiles, ...dougsClaudeEntryFiles);
    filesTouched.push(...ourConversationsFiles, ...ourConversationsEntry.files);
    const namedProjects = reading.projects.filter(candidate => candidate.name !== '');
    const scheme = schemes[(namedProjects.findIndex(candidate => candidate.id === project.id) + 1) % schemes.length];
    const writtenProjectBook = projectBook(folders, project, scheme, args.overwrite);
    filesTouched.push(...writtenProjectBook.files);
    filesTouched.push(...registerEntry(
        folders, folders.claude, project.name, writtenProjectBook.folder, project.updatedAt, projectCaption, '**',
    ).files);
    const namesTaken = new Set<string>();
    let writtenCount = 0;
    let keptCount = 0;
    for (const conversation of chosenConversations) {
        const heldRecord = heldRecords.get(conversation.id);
        const heldBookFolder = heldRecord === undefined
            ? undefined : join(folders.conversations, heldRecord.record.bookFolder);
        const bookStands = heldBookFolder !== undefined && existsSync(heldBookFolder);
        const standingRecord = bookStands ? heldRecord : undefined;
        const state = importState(conversation, folders.conversations, standingRecord?.record);
        if (standingRecord !== undefined && (!args.overwrite || state === 'edited')) {
            keptCount++;
            continue;
        }
        const name = standingRecord?.record.name
            ?? uniqueBookName(folders.conversations, conversation.name, namesTaken);
        const path = shownPath(conversation);
        const writtenBook = conversationBook(folders, conversation, path, name, [project.name], scheme, referents);
        const conversationCaption = `A conversation, ${countedNoun(path.length, 'exchange')}:`;
        const entry = registerEntry(
            folders, folders.conversations, name, writtenBook.folder, conversation.updatedAt,
            conversationCaption, '**', recordAppendix,
        );
        const entryStem = entry.entryPath?.replace(/\.tsx$/u, '');
        const newRecordPath = entryStem === undefined ? undefined : `${entryStem}${recordSuffix}`;
        const recordPath = standingRecord?.path ?? newRecordPath;
        if (recordPath === undefined)
            throw new Error(`no entry stands for "${name}" in ${folders.conversations}, so its record has no place`);
        const bookFolder = basename(writtenBook.folder);
        const record = importRecord(conversation, folders.conversations, name, bookFolder, reading.exportedOn);
        writeImportRecord(recordPath, record);
        filesTouched.push(
            ...writtenBook.files,
            ...entry.files,
            recordPath,
            ...projectEntry(folders, writtenProjectBook.folder, name, writtenBook.folder, conversation.createdAt),
        );
        writtenCount++;
    }
    filesTouched.push(...orderRegisterTable(folders.conversations), ...orderRegisterTable(folders.claude));
    console.log(`\nwrote ${countedNoun(writtenCount, 'conversation')}, kept ${keptCount}, `
        + `${countedNoun(filesTouched.length, 'file')} touched under ${folders.claude}`);
};

const flagValue = (argv: string[], flag: string): string | undefined => {
    const flagIndex = argv.indexOf(flag);

    return flagIndex >= 0 ? argv[flagIndex + 1] : undefined;
};

const countedNoun = (count: number, noun: string): string => `${count} ${noun}${count === 1 ? '' : 's'}`;
const elapsedSeconds = (since: number): string => `${((Date.now() - since) / 1000).toFixed(1)}s`;

const invokedDirectly = process.argv[1] !== undefined && resolve(process.argv[1]) === fileURLToPath(import.meta.url);
if (invokedDirectly)
    run(parsedArguments(process.argv.slice(2))).catch(error => {
        console.error(String(error.message ?? error));
        process.exit(1);
    });
The Export
What is read, and where it is found: the export Claude gives of an account, and the mapping of conversations to projects read off the application, both left where they land.
A manifest and four archives
An export of my Claude account arrives as a small manifest naming four archives, which the browser must fetch since their links are single-use: the account's metadata, its projects with every knowledge file inline, its memories, and every conversation in one array, with every message as a tree of blocks, text, thinking, a tool used and what it returned, and the artifacts among them. The export says nothing about which project a conversation belongs to; that is read off the application by a capture that takes the screen, and written as a mapping beside the export.
All of it lands in a sister repository on this machine, in dated folders, by that repository's own command; a fresh export is made there on my go-ahead, since the capture takes my screen. The importer reads the newest export and the latest mapping where they stand, and copies none of it into the library. It never reads the markdown that repository wrote from the export, which kept only the text and walked the tree as a list; the code there was the beginning of this, and the archive there is the check.

The Record
One record for every source: a conversation with its messages as a tree of blocks, and a project with its documents and its memory; each source a reader into it, and nothing after the reading knows a source's words.
The seam
Every source I have spoken to Claude through is packaged its own way, and every one holds the same things: a conversation with a name and its times, its messages in a tree, since a message edited or asked again makes a branch, each message by someone at an instant and made of blocks; and a project with a name, a description, its knowledge files and what Claude remembers of it. The record is those things in this library's words, and a reader is the forty lines that rename one source's words into them, once. The stages after the record never see a source, so the second source, the sessions of Claude Code on this machine, is one more reader and nothing else moves.
The Claude export's reader streams the one array of conversations, cutting each loose as it closes, so what is held at any moment is one conversation and not the archive, and reads the small archives by their directory; the whole export is read in under twenty seconds without a dependency. The export's own names, the ones its schema gives, appear in the reader and nowhere else.

The Pairing
Which project a conversation belongs to, by evidence the importer names and I dispose of, and which conversations are not mine and stay out.
The machine proposes and I dispose
The export pairs nothing: two records in five hundred name a project. So the importer gathers evidence and says it by name. A conversation that searched its project's knowledge and was answered with a document the project holds is paired by that document, with certainty. The mapping captured off the application pairs by title, with its relative date and its position to tell apart the ten conversations that share one name. A project's memory may name a conversation. For a session of Claude Code the working folder is the project. Where the evidence agrees the conversation is paired; where it conflicts or is silent the conversation is left unpaired and reported, and it has its home in the book that catalogues all of them either way.
The pairing stands as a file beside this chapter, one line per conversation with its project and the evidence, and I edit it: a line I write is read before any evidence. The same file holds the exclusions. A conversation that is not mine, one filed under a project of Ana's, or one with a title in Russian, is proposed for exclusion and stays out unless I strike the line; nothing is excluded by language alone, since I write Russian too.

The Ledger
What the importer wrote, kept as a record beside each conversation's entry in the book that holds them all, so that it knows which conversations are already in, which have grown since, which are new, and which I have edited by hand and it must never touch.
A record beside every entry
Many conversations are short, and after a few runs it is hard to know which are in. So the importer keeps its ledger in the conversations book itself: beside each entry of the register of all my conversations stands a file named for the entry, the record of that conversation's import, with the conversation's id, the name and folder of its book, the export it was read from, the export's time of last change and its count of messages at the import, and the digest of the files written. The entry lists the file, so the binder accounts for it, and reads nothing of it, since a resource is shown and never interpreted. A conversation with no record is new. One whose export now shows a later time or more messages has grown since, and is reported. One equal to its record is in. And one whose files no longer match their digest has been edited by hand, and the importer never touches it, whatever flag the run was given.
The record stands with the entry, so what I do to a conversation by hand, cutting it, renaming it, striking it from the register, carries its record along or removes it, and the state of the import is never a file apart that can disagree with the books. While the importer is being made it overwrites what it wrote, on a flag said at the run, since the shape of a book is still being decided on its page. Once it is done the flag goes, and a conversation once imported is mine: cut into days or sittings, summarized, annotated, by hand.

The Thread
The conversation as it stood on the screen, which is one path through a tree, and the count of what was left on other paths.
A tree, and the path a reader sees
Every time I edit a message or ask for another answer, the conversation branches, and what the application shows me is never the tree but one path through it, from the first thing said to whichever end I was last standing on. Each message carries the one it was said after, so the path is a walk: take the latest message nothing answers, follow the parents to the root, and turn it around. That path is the conversation as far as a reader is concerned, and the importer says what it left behind rather than rounding it off: a conversation of a hundred and six messages that shows eighty-four has twenty-two on other paths, and the cover says so.

The Writing
What was said, turned into this library's writing once, on the way in, and never read from a string when a page is drawn.
Once, on the way in
A message's text comes out of the export as markdown, and what belongs in a library is writing. The conversion happens here, once: a message becomes an exchange of a conversation, headed by who said it and told its instant, and what was said becomes paragraphs, lists, headings, code, tables, formulas, a word set bold or in emphasis, a word typed as code said verbatim, a quoted paragraph said quoted, and a link to the web a word that refers to it. The markup of the file it lands in is the library's own, expanded, one element to a line, so the checker that reads the shape of every file here reads these too.
A search of the web or a run of code that Claude made becomes one paragraph saying what was done and the paragraph after it saying what came back. An artifact the conversation made becomes a file beside the chapter, every version of it, its updates replayed, with a paragraph naming it where it was made. The text of a file pasted or attached becomes a file beside the chapter too; an uploaded file, whose content the export never carries, is named and no more. The thinking behind an answer is counted and left out.

The Books
What is left on disk: a conversation as a book, every conversation filed under one book that catalogues them all, and a book per project that catalogues its own besides.
One home, and as many catalogues as I like
A conversation is a book: its book file one line, its cover saying when it was held and how many messages it holds, its synopsis what it came to, its table, and in the first version one chapter holding every exchange. It is filed under the book that catalogues all of my conversations, which is its one home whatever the mapping says. Each project that catalogues it is a book of its own, a project book, a reference manual of the project's knowledge files and a catalogue of its conversations by topic, which is the way back from a conversation to its project; and a project's book is a subject, so what I later write about a project can be filed under it. Both kinds of catalogue are filed under Dougs Claude, the book that catalogues the conversations book and the project books together. The catalogue of all of them is a very simple book for now; the shelves and the tables that catalogue them more effectively come with their pages.
A book's name is its title, an untitled conversation numbered Untitled 1 and on by a count the importer keeps, a repeated title the same, and never a date, since a conversation happens across time. A folder that exists is never entered unless the run says to overwrite and the ledger says the book is still the importer's; a catalogue's chapter and row are added where its table lacks the reference.

The Check
What the importer wrote, checked against the archive the export was first read into, and then against the bind.
Two readings of one export
The sister repository holds an older reading of the same export, as markdown: a transcript per conversation with its count of messages, a book per project with the conversations its scaffold filed there, and the statistics of the whole. The importer never reads that archive as a source, but it is a check: every count of ours against its statistics, our pairing of a project against its scaffold's, our count of messages in each conversation against its transcript's, every difference listed by name in the report. Then the bind, which holds every book to its type and every reference to its place; and the run reads every conversation it has written back through its record, the instants of its messages in order, and finds them equal to the thread or says from which message they stray.
The run reports the check whether it writes or not, after the project's conversations: the counts of the whole export against the statistics, the project's conversations we paired against the ones the scaffold filed, each conversation's messages against its transcript's count, and what stands written against the export. A difference is not a fault; the archive's reading is older and its own, and the report is where the two are read side by side.
