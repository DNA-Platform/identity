For a rolling enjoyment z-score, use this formula in the Calculations sheet:
text
=ARRAYFORMULA(
  IF(ROW(A:A)=1, "Enjoyment Z-Score",
  (D:D - 
   AVERAGE(OFFSET(D2, MAX(ROW(D2:D)-10-ROW(D2),0), 0, MIN(ROW(D2:D)-ROW(D2)+1,10)))) /
   STDEV(OFFSET(D2, MAX(ROW(D2:D)-10-ROW(D2),0), 0, MIN(ROW(D2:D)-ROW(D2)+1,10)))
  )
)
This:
Uses 10-day rolling window
Calculates z-score using (value - mean) / std
Handles header row
Adjusts window size for start of dataset
