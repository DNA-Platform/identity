Semantic Reference Theory: Overview and Quantification Syntax
Semantic Reference Theory (SRT) is a first-order logical theory that provides a formal substrate for meaning through the fundamental concepts of referents and references. Unlike set theory, SRT begins with reference itself as the primitive notion.
Core Structure
The theory centers around a ternary relation R(x,y,t) expressing that referent x relates to referent y through relationship type t. This is notated as:
srt
x =t> y
The domain consists of referents organized into a catalogue - a finite collection of related referents that form a semantic structure.
Quantification Syntax
SRT uses a programming-inspired notation to make formal logic more accessible without special typesetting:
Universal Quantification:
Ax: P(x) - "for all x, P(x) holds"
A[x]: P(x) - equivalent bracket form
Ax.Ey: R(x,y) - "for all x, there exists y such that R(x,y)"
A[x].E[y]: R(x,y) - equivalent bracket form with brackets
Existential Quantification:
Ex: P(x) - "there exists x such that P(x)"
E[x]: P(x) - equivalent bracket form
E[x,y]: R(x,y) - "there exist x and y such that R(x,y)"
The bracket notation [x] provides visual clarity for complex quantifications and allows multiple variables to be quantified together as in E[x,y,z].
Key Design Principles
Programming-style syntax: Makes formal logic typeable without special symbols
First-order foundation: Maintains completeness while allowing axiom schemas in theory extensions
Semantic neutrality: Core axioms must be consistent with an empty catalogue
Transduction operators: Allow theory evolution through linguistic transformations
The Point About Quantification
The quantification syntax in SRT demonstrates several important principles:
Accessibility: By using ASCII-friendly notation (Ax, Ex), the theory can be expressed in any text editor
Composability: The dot notation (Ax.Ey) allows natural chaining of quantifiers
Flexibility: Bracket forms provide both clarity and the ability to quantify multiple variables simultaneously
Semantic preservation: The notation maintains the full expressive power of first-order logic while being more approachable
This approach to quantification reflects SRT's broader philosophy: formal rigor need not require austere notation. By making the syntax more accessible, SRT invites broader participation in formal semantic reasoning while maintaining mathematical precision.
The quantification syntax also supports SRT's goal of being self-representing - a theory that can easily express its own structure within its formalism, avoiding the notational barriers that often separate formal systems from their meta-theoretical descriptions.

I. Advanced Quantification Syntax
Basic Quantifier Notation
SRT extends first-order logic with programming-inspired syntax for clearer expression:
text
A[x]: P(x)                    // for all x, P(x) holds
E[x]: P(x)                    // there exists x such that P(x)
A[x]:E[y]: R(x,y)            // for all x, there exists y such that R(x,y)
Distinguished vs Possibly-Equal Quantification
text
E{x,y}: P(x,y)               // x and y may be equal
E[x,y]: P(x,y)               // x and y must be distinct
Where formally:
text
E[x,y]: P(x,y) := E{x,y}: x != y & P(x,y)
Constrained Quantification
When the bound variable appears first in the constraint:
srt
A(x => o):E(y != x):A(z =t> y): P(x,y,z,t)
When it doesn't appear first, explicit binding is required:
srt
A(x: o => x):E(y: x != y):A(z: y =t> z): P(x,y,z,t)
Mixed Grouping
Complex distinction patterns:
text
E[{x,y},z]: P(x,y,z) := E[x,y,z]: x != y & P(x,y,z)
E[x,{y,z}]: P(x,y,z) := E[x,y,z]: y != z & P(x,y,z)
Bracketing Operators
For complex expressions:
text
:&:  // AND with new scope
:|:  // OR with new scope  
:||: // XOR with new scope

Basic Reference Notation
srt

x !<=>! y   // no bidirectional reference

srt

The Subject-Object-Relationship Axiom
srt
E[{s,o,r}]:A[x,y,t: x =t> y]: t --> r & y =o> y & (x != y => x =s> x) & (x == y => x =o> x)
This establishes:
All relationship types inherit from r
Objects always have property o
Distinct subjects have property s
Self-reference makes something purely objective
The Representation Axiom
srt
E[{sym,rep}]:A[x,y]: x =x> y =|> x --> rep :&: x == (x,y) =|> x --> sym
This establishes:
Things that represent inherit from rep
Symbols (where x equals the most specific relationship) inherit from sym
Therefore: sym --> rep (symbols are a special case of representation)
The Most Specific Relationship Axiom (Distinct Case)
For x != y:
srt
A[x,y: x != y]:E[t: x =t> y]:E[sp: x =sp> y]: sp --> t !--> sp :&: A[p,q]: p =sp> q => (p == x & q == y)
This establishes that for distinct pairs:
There exists a most specific relationship sp
It inherits from all other relationships between them
It is unique to that pair

For x == y, the evaluation of (x,x) depends on x's properties:
srt
(x,x) := x =sym> x ? x : x =s> x ? (x) : eq
Where:
If x is symbolic: (x,x) evaluates to x itself
If x is subjective: (x,x) evaluates to (x)
If x is purely objective: (x,x) evaluates to eq
