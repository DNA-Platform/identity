Looking at the stack trace, you have a circular dependency between getPrototype() and getType() when handling primitives.
The issue is in your getType() method:
typescript
if (this.isPrimitive() || this.isType()) {
    this[$type$$] = this.$prototype.$type.$of(this);  // <-- This accesses $prototype
}
And in getPrototype():
typescript
else if (this.isPrimitive())
    this[$prototype$$] = this.$type.$prototype.$of(this);  // <-- This accesses $type
This creates an infinite loop:
isPrimitive() → getType() → accesses this.$prototype
Which calls getPrototype() → accesses this.$type
Which calls getType() → accesses this.$prototype
And so on...
The Fix
For primitives, you need to get the type directly without going through the prototype:
typescript
protected getType(of?: $ObjectiveRep): $ObjectiveRep {
    if (!this[$type$$]) {
        if (this.isNullOfUndefined()) {
            this[$type$$] = $type(undefined).$of(this);
            return this[$type$$];
        }
        if (this.isPrimitive()) {
            // For primitives, get type directly to avoid infinite recursion
            const typeLiteral = primitives.get(typeof this[$literal$]);
            if (typeLiteral) {
                this[$type$$] = $type(typeLiteral).$of(this);
            } else {
                this[$type$$] = $type(undefined).$of(this);
            }
        } else if (this.isType()) {
            // For types, we can safely access prototype
            this[$type$$] = this.$prototype.$type.$of(this);
        } else {
            this[$type$$] = $typeof(this[$literal$]).$of(this);
        }
    }
    return of ? this[$type$$].$of(of) : this[$type$$];
}
The key difference is that for primitives, we directly look up the type constructor from the primitives map instead of trying to go through the prototype chain, which breaks the circular dependency.
